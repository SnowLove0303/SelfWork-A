## 二、上下文专属工具栏（Contextual Tabs）

当光标进入特定对象（如表格、图片、公式、页眉页脚）时，WPS 会动态激活专属上下文 Tab：

### 1. 表格工具 (`CT_TableTools.kuip` + `CT_Design.kuip`, 119 commands)
| 分组 | 工具项 | SelfWork `TableBlock` 状态 |
|---|---|---|
| **行和列 (`Rows and Columns`)** | 上/下方插入行、左/右侧插入列、删除单元格/行/列/整表、绘制表格、擦除框线 | ✅（已实现全向插入与删除、悬停行列 `+` 插入器） |

## 三、右键上下文菜单精选 (`PopupMenu.kuip`)

WPS 针对不同光标上下文提供精准的右键菜单与顶部 **Mini Toolbar（浮动微工具栏）**：
1. **正文/选区右键**：顶部 Mini Toolbar（字体/字号/加粗/斜体/下划线/高亮/字色/格式刷）+ 剪切/复制/粘贴（纯文本/保留格式）/字体/段落/项目符号/编号/超链接/批注/翻译。
2. **表格右键**：顶部 Mini Toolbar + 插入（上方行/下方行/左侧列/右侧列）+ 删除（单元格/行/列/整表）+ 合并/拆分单元格 + 平均分布各行/各列 + 单元格对齐（9宫格）+ 边框和底纹 + 表格属性。
3. **图片右键**：更改图片、裁剪、图片另存为、环绕方式、设置对象格式。

## 四、SelfWork 文档工具后续演进优先级建议

结合 SelfWork **“Local-First + 轻量少字 + Notion/Word 混合体验”** 定位，建议按以下优先级渐进补齐高频刚需工具：

| 优先级 | 优化方向 | 具体能力点 | 对标参考 |
|:---:|---|---|---|
| **P0** | **表格引擎高阶闭环** | 1. 基于已有二维框选支持**合并单元格**与**拆分单元格**；<br>2. 列数据**升序/降序排序**与数值列快捷统计（求和/均值）；<br>3. 单元格文本转纯文本 / 复制为 Markdown / HTML | `CT_TableTools.kuip` |
| **P0** | **划选与段落格式化增强** | 1. 划选工具栏补充**上下标**、**一键清除格式**、**行内公式**；<br>2. 段落级菜单补充**行距切换**（1.0 / 1.5 / 2.0）与**字体大小写转换** | `CT_Home.kuip` |
| **P1** | **一键排版清理工具（文字工具）** | 在文档工具菜单内置实用排版微工具：一键去除多余空行、一键清理段首空格、标点全半角规范化 | `WordTools.kuip` |
| **P1** | **格式刷与公式快选** | 1. `FormatPainter` 跨块/跨选区格式刷；<br>2. `MathBlock` 增加常用公式符号（分式/根号/上下标/希腊字母）快速点击插入栏 | `CT_Home.kuip` / `CT_EquationTools.kuip` |
| **P2** | **导出与对比增强** | 1. 支持单篇文档一键导出为精美排版 PDF / Word (`.docx`)；<br>2. 版本历史抽屉 (`DocHistoryDrawer`) 增加与当前正文的 Diff 高亮对比 | `CT_File.kuip` / `CT_Review.kuip` |
