# 变更提案：选区单一权威归一化与消除双重高亮叠加 (Proposal)

## 一、 需求背景与动机
用户在实际体验中指出现象：
> “现在好像会双重选中，又选中字，又选中行，导致双重高亮，你看是不是呢”

经深度逆向归因分析，确认当前存在**双轨选区机制互不互斥与高亮图层叠加**的问题：
1. 鼠标跨段划选时，浏览器原生 Selection 机制仍在后台运行并在当前段落行内生成原生选区（表现为选行或选词）；
2. 与此同时，底层的 W3C CSS Custom Highlight 也在按照鼠标坐标独立绘制字符高亮；
3. 两套机制同时激活，屏幕上同时出现原生选区（选行）与自定义 Highlight（选字）；在两者重合处，`::selection` 与 `::highlight` 的半透明水蓝色彩双重叠加，导致选区发黑发暗、饱和度过高、边缘参差不齐。

本提案确立**选区单一权威法理（Single Source of Authority）**：
- 严格禁止两套选区并存；
- 当跨段划选激活时，立即调用原生选区抑制与清除逻辑，将整个可视呈现全权收敛至唯一的 `CSS.highlights` 字符 Range；
- 彻底消除“又选行又选字”的双重选区混乱，确保高亮图层 100% 单层渲染，通透纯净。

## 二、 1:1 Spec-Kit 需求对账矩阵 (RTM)

| 需求条目序号 | 原始意图指纹 | 对应规格契约 | 验收判定依据 |
| :--- | :--- | :--- | :--- |
| **REQ-SINGLE-SELECT.1** | 彻底消除“双重选中”，选区权威单一归一化 | 跨段拖选时强制清除非权威的原生选区残影，确保屏幕上始终只有唯一一套干净自洽的选区 | 划选时只有一套精准贴合字形的选区，绝不出现第二重行选区或块选区 |
| **REQ-SINGLE-SELECT.2** | 消除色彩双重叠加，统一单一层级纯净色彩 | 消除 `::selection` 与 `::highlight` 的重叠渲染，确保文字背景色仅有一层均匀半透明水蓝 | 选中文本色彩均匀通透，绝无深浅不一或色彩叠加发黑现象 |
| **REQ-SINGLE-SELECT.3** | 零延迟极致跟手与字符级精度 100% 保持 | 维持 0 次 React Re-render 与 GPU 硬件加速着色，字符级精确起止与 120Hz 跟手性能绝对不退化 | 鼠标划选丝滑跟手无顿挫，指哪选哪，无任何卡顿 |
| **REQ-SINGLE-SELECT.4** | 剪贴板复制所见即所得真实核销 | 复制（`Ctrl+C`）精准提取那唯一一层高亮文字切片，屏幕所见与剪贴板所得 100% 绝对一致 | 复制内容严格等于屏幕高亮文字，无冗余未选字符溢出 |
