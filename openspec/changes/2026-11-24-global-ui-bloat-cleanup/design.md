# Design: 全工作台 UI 少字去噪方案

遵循 `ui-ux-design-engineering` 技能第六节 `RADICAL_TEXT_ECONOMY_AXIOM`：
1. **ProcessManifestModal**：移除每行底部文件路径（保留至 `title` 悬停提示），移除单行冗余分类标签，精简分组标题为 `组合` / `应用`；
2. **LauncherDashboard**：移除分屏套件副标题长句、弹窗内所有括号/引导说明；
3. **Docs & Database**：移除模板引导语、同步块长段说明、图片块占位提示，空状态统一收敛为 3~4 字短语；
4. **MindMap**：移除废纸篓长句说明，精简新建按钮文案。
