# Proposal: 剔除虚假功能，全面重构为「私人/最近/收藏」三层分区管理与笔记数据库架构

## 1. 业务背景与问题驱动
通过对界面实际运行效果的实测与用户反馈，原 UI 中包含若干源自 Notion 截图的占位装饰元素（如侧栏顶部的“主页”、“新对话”、“外部代理”，顶栏的“上次编辑 刚刚”、“共享”、“复制链接”，以及硬编码的“Jr Forever 的工作空间 总部”）。这些元素在本地桌面环境中无真实业务支撑，严重干扰了工作台的纯净性与可用性。

必须坚决彻底剔除所有不可点击、无业务支撑的虚假 Mock 功能，全面重构为 100% 具备本地 SQLite 物理持久化支撑的真实可用架构：
1. **三大法定默认总模块**：
   - **私人 (Private)**：用户个人核心工作区，支持在其中**任意建立子分区（分类文件夹/目录）**；
   - **最近 (Recent)**：动态聚合最近访问或编辑过的笔记/数据库（按 `updatedAt` 倒序）；
   - **收藏 (Favorites)**：动态聚合用户点亮星标 ⭐ 的笔记与数据库；
2. **子分区多维能力**：
   - 在私人模块及其下属任意子分区中，允许**创建「笔记数据库」**（一个数据库容纳多篇笔记，每篇笔记既有表格属性又有独立正文，支持 Side Peek 侧边预览与全屏编辑）；
   - 允许直接**创建「独立笔记」**（单篇轻量 Markdown/富文本页面，随心记录灵感）。

## 2. 1:1 需求对账矩阵注入 (Spec-Kit RTM Alignment)
- **REQ-CLN-01**: 彻底剔除侧栏假入口（主页、新对话、外部代理）、顶栏假按钮（共享、复制链接等）与假团队空间名称；
- **REQ-PART-02**: 构建三大法定默认总模块（私人、最近、收藏），各自支持独立平滑折叠/展开；
- **REQ-PART-03**: 私人模块支持任意建立、重命名、删除子分区（分类目录），维护清晰的树状归属；
- **REQ-DB-04**: 子分区与私人根目录下支持建立「笔记数据库」（包含多篇笔记，支持多维字段属性与富文本正文）；
- **REQ-NOTE-05**: 子分区与私人根目录下支持直接创建「独立笔记」（纯净块级文档，支持星标收藏与本地持久化）。

## 3. 验收标准与交付物
1. 界面上彻底清除全部不可用的 Mock 假入口与硬编码文本；
2. 侧栏清晰呈现【私人】、【最近】、【收藏】三大模块；
3. 在【私人】模块下点击「+ 新建子分区」，可即时生成自定义子分类并持久化到 SQLite；
4. 在子分区内点击「+ 数据库」能创建笔记数据库，点击「+ 笔记」能创建独立单篇文档；
5. `cargo test` 单测全绿通过（退出码 0），`tsc --noEmit` 零告警、零错误。
