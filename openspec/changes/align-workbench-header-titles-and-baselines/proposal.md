# Proposal: 对齐待办清单与思维导图顶栏标题坐标与全局水平基准线

## 1. 提案背景与事实指纹溯源
- **原始需求指纹**:
  > “思维导图 的 分区管理和 待办清单的待办清单 两个标题间的位置不统一，切起来很怪啊， 懂我意思？”
- **问题根因定位**:
  - `MindMapPartitionView.tsx`（思维导图）与 `MemoBoard.tsx`（灵感便签）的顶栏高度均严格锁定在 `h-[49px]`，子元素采用 `flex items-center` 垂直居中，标题 Y 轴几何中心位于 `24.5px`；
  - `TasksPanel.tsx`（待办清单）顶栏采用了复合复合结构 `p-3.5 pb-2.5 space-y-3`，将标题行、状态过滤胶囊与单行录入框挤压在同一个顶栏容器中。行高受过滤按钮影响扩展至 ~30px，加上 `padding-top: 14px`，导致“待办清单”标题文本的垂直中心位于 `28px~29px`；
  - 切换模块时，由于存在 ~4.5px 的 Y 轴垂直位移与基准高度差异，用户视线焦点在左上角产生突兀的跳移与不协调感。

## 2. 1:1 需求物理对账矩阵 (RTM)

| 需求编号 | Spec-Kit 需求条目 | 拟定解决方案与边界 | 验收充要条件 |
| :--- | :--- | :--- | :--- |
| `REQ-TITLE-ALIGN-01` | 左上角标题绝对坐标像素级锚定 | 在 `TasksPanel.tsx` 提取顶标头行为独立的 `h-[49px] px-3.5 flex items-center justify-between border-b` 容器，与 `MindMapPartitionView.tsx` 严格一致。 | 切换模块时，左上角标题文字（“待办清单”与“分区管理”）在屏幕上的物理坐标无任何垂直与水平抖动。 |
| `REQ-TITLE-ALIGN-02` | 顶栏标准高度与水平基准分割线零落差贯穿 | 确保待办清单首行顶标底部分割线位于 Y=49px，使得待办清单与灵感便签在内部也形成连续统一的 Y=49px 水平分割线。 | 工作台内待办、便签、导图大盘首行顶栏高度完全为 `49px`。 |
| `REQ-TITLE-ALIGN-03` | 快速录入框与交互流无损解耦 | 将待办任务快速录入输入框从顶标头行解耦，作为独立的次级操作栏平铺放置，样式优雅自然，快捷交互手感不受影响。 | 回车秒建任务功能 100% 正常，过滤胶囊与统计徽标位置和谐。 |
| `REQ-TITLE-ALIGN-04` | 既有功能与全局承重墙保护 | 严格保留所有既有待办状态机、排序、便签联动以及 `Sidebar.tsx` / `Titlebar.tsx` 源码。 | `Sidebar.tsx` 与 `Titlebar.tsx` 0 行修改，原有功能零退化。 |
