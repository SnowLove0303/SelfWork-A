# Proposal: 全局字体字号分类规范落地与跨模块布局基准线条严密对齐

## Why (变更背景与问题陈述)
用户提出三个核心关键问题：
1. **全局字体字号未分类统一**：“全局的字体字号要做统一一些，做些分类，比如模块标题啊模块内容啊之类的分别要用什么字体字号”；
2. **跨模块切换视觉突兀**：“UI上尽量做好模块间的对齐，比如待办清单切到思维导图，会有种突兀的感觉”；
3. **思维导图栏目线条错位落差**：“思维导图分区管理的栏目与栏目间的线条要对齐，这种线条问题之前有在其他地方强调过”。

经深度对齐审计发现：
- 待办清单（`TasksPanel` / `MemoBoard`）顶栏高度为严格的 `h-[49px]`，主标题为 `text-xs font-semibold`，微章为 `text-[10px]`；
- 而思维导图（`MindMapPartitionView`）左侧分区顶栏使用 `py-4`，右侧大盘顶栏使用 `py-4 px-8` 且标题放大为 `text-base`（16px）；由于左右两边包含的控件高度不同（右侧放了搜索输入框），导致左侧横线与右侧横线产生明显的垂直 Y 轴错位；且从待办清单切换到思维导图时，顶栏位置跳动、字号膨胀、内边距突然从 `px-3.5` 变为 `px-8`，引发强烈的突兀感。
