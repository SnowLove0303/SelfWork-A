# 规格契约：大纲面板收起按钮彻底清除与智能多层级父子折叠系统 (Specification)

## 1. 范围与定义

本规格定义 SelfWork 文档编辑器右侧目录大纲栏的单一控制入口净化规范，以及基于标签权重与语义编号自愈的多层级深度父子折叠契约。

## 2. 行为契约 (RFC 2119 标准)

### 2.1 大纲侧栏内部收起按钮清除契约 (REQ-TOC-2.1)

- **SHALL**: 系统 **SHALL** 彻底移除大纲侧栏头部右侧的 `PanelRightClose` 图标按钮。
- **SHALL**: 顶栏右侧的「目录大纲」按钮 **SHALL** 作为整个大纲侧栏展开与收起的唯一、权威控制开关。
- **SHALL**: 大纲侧栏头部 **SHALL** 仅保留「大纲 / 图谱」标签页切换器，右侧留空或对齐，杜绝控件功能重合。

### 2.2 智能多层级深度父子折叠契约 (REQ-TOC-2.2)

- **SHALL**: 系统 **SHALL** 采用「基础标签等级 + 语义编号启发自愈」算法计算每个大纲项的真实层级深度 $D$：
  - 若为 `h1`，则基础深度 $D = 1$；
  - 若为 `h2`：
    - 若文本匹配点分数字编号（如 `1.1`、`1.2`、`2.1.3` 等 `/^\d+\.\d+/`），则深度自愈为 $D = 3$；
    - 否则保持 $D = 2$；
  - 若为 `h3`，则基础深度 $D = 3$（若包含二级以上点分编号如 `1.1.1`，可自愈为 $D = 4$）。
- **SHALL**: 对于任意大纲节点 $H_i$（无论是 H1 还是 H2）：
  - **WHEN** 其后续紧邻出现一个或多个满足 $D(H_k) > D(H_i)$ 的子节点（直到遇到 $D \le D(H_i)$ 为止）时；
  - 该节点 **SHALL** 标记为 `hasChildren = true`，并计算直接或间接包含的子节点总数 `childCount`；
  - 该节点左侧 **SHALL** 渲染独立的折叠微箭头（`ChevronDown` 展开 / `ChevronRight` 折叠）。
- **SHALL**: 点击二级父节点（如 `一、集合到底是什么？`）左侧箭头时：
  - 系统 **SHALL** 仅将其下属的子节点（如 `1.1`、`1.2`、`1.3`）折叠隐藏；
  - 系统 **SHALL NOT** 影响同级其他二级节点（如 `二、可变集合：set`）或其上级一级大章；
  - 该二级父节点右侧 **SHALL** 呈现收拢徽标（如 `+3`）。
- **SHALL**: 点击一级父节点（如 `第一部分`）左侧箭头时：
  - 系统 **SHALL** 将其下属的所有二级节点与三级小节整体折叠隐藏。
- **SHALL**: 点击标题文本主体时：
  - 系统 **SHALL** 触发平滑滚动穿梭定位，保持与折叠箭头事件的物理隔离 (`stopPropagation`)。
- **SHALL**: 大纲顶栏一键「全部折叠 / 全部展开」按钮 **SHALL** 联动所有有子项的父级节点（包括 H1 与 H2）。
