# Design: Docs Table Word-Style Toolbar Categorization and Reorganization

## 1. 架构总览与分层设计 (Architecture Overview)

针对用户指出的“工具栏分类做太差了”问题，本设计参考 **Microsoft Word (及 WPS Writer)** 的表格专业工具分类标准，结合 **Notion** 的块级微手柄设计，构建出高内聚、低耦合的四维正交工具矩阵：

```text
┌────────────────────────────────────────────────────────────────────────┐
│             【Word-Style Table Toolbar Categorization Matrix】         │
│                                                                        │
│   1️⃣ 结构与行列 (Structure & Rows/Cols)                                │
│      • 插入: 在上方插入行 / 在下方插入行 / 在左侧插入列 / 在右侧插入列    │
│      • 删除: 删除当前行 / 删除当前列 / 删除整个表格                      │
│      • 几何分布: 平均分布各行 / 平均分布各列 / 自动调整列宽              │
│                                                                        │
│   2️⃣ 对齐与几何 (Alignment & Cell 9-Grid)                             │
│      • 水平维度: 左对齐 · 居中对齐 · 右对齐                            │
│      • 垂直维度: 顶端对齐 · 垂直居中 · 底端对齐                        │
│      • 交互控件: 3×3 矩阵九宫格交互图形选择器                          │
│                                                                        │
│   3️⃣ 样式与底纹 (Style & Shading)                                     │
│      • 单元格底色: 预设 8 色优雅暗黑低饱和莫兰迪色卡 (无/灰/蓝/绿/黄/紫)│
│      • 表格结构开关: 表头行 (Header Row) · 斑马纹 (Banded Rows)        │
│                                                                        │
│   4️⃣ 内容与富文本 (Content & Rich Text)                               │
│      • 行内格式: 加粗 B · 斜体 I · 下划线 U · 删除线 S · 代码 <> · 标记 🎨│
│      • 剪贴板与数据: 矩阵复制 (TSV/Markdown) · 批量清空 · 智能粘贴     │
└────────────────────────────────────────────────────────────────────────┘
```

## 2. 界面载体呈现层级 (Surface Architecture)

### 2.1 Surface A: 右键菜单层级 (Word-Style Context Menu)
```text
┌────────────────────────────────────────────────────────────────┐
│ [Mini Toolbar]  [B] [I] [U] [S] [🎨] [🪣底纹▼] [📐9宫格▼] [Tx]   │
├────────────────────────────────────────────────────────────────┤
│ 📋 剪贴板                                                      │
│    • 复制表格切片 (Ctrl+C)                                     │
│    • 批量清空所选内容 (Delete)                                 │
├────────────────────────────────────────────────────────────────┤
│ ➕ 插入                                              ▸         │
│    (子菜单: 在上方插入行 / 在下方插入行 / 在左侧插入列 / 在右侧插入列)│
├────────────────────────────────────────────────────────────────┤
│ 🗑️ 删除                                              ▸         │
│    (子菜单: 删除选中行 / 删除选中列 / 删除整张表格)            │
├────────────────────────────────────────────────────────────────┤
│ ⚖️ 尺寸与分布                                                  │
│    • 平均分布各行                                              │
│    • 平均分布各列                                              │
└────────────────────────────────────────────────────────────────┘
```

### 2.2 Surface B: 表格常驻工具条 (Table Action Bar)
当表格被聚焦时，在表格右上角展现极简胶囊组：
- `[ 📐 对齐 ]` -> 点击弹出 9 宫格选择器
- `[ 🪣 底纹 ]` -> 点击弹出颜色面板
- `[ ⚙️ 布局 ]` -> 点击展开行列与分布菜单
- `[ 📄 样式 ]` -> 快速切换表头行与斑马纹

### 2.3 Surface C: 悬停把手 (Hover Grippers)
- 表头各列顶部：悬停显示 `···` 列把手，点击弹出列操作（整列对齐、整列底色、向左/向右插列、删列）；
- 每行最左侧：悬停显示 `⠿` 行把手，点击弹出行操作（向上/向下插行、清空行、删行）。

## 3. 数据结构扩展与状态持久化

在 `TableData` 与 `Block` 属性中安全扩展（保证向下兼容）：
```typescript
interface TableCellData {
  text: string;
  bgColor?: string; // 单元格底色（如 "rgba(56, 189, 248, 0.15)"）
  verticalAlign?: 'top' | 'middle' | 'bottom'; // 垂直对齐
}

interface TableProps {
  rows: TableCellData[][];
  columnAlignments?: ('left' | 'center' | 'right')[];
  columnWidths?: number[];
  hasHeaderRow?: boolean;
  hasBandedRows?: boolean;
}
```
向下兼容防线：若 `rows` 中单元格为纯字符串，`healTableRows` 自动归一化为 `{ text: str }`，100% 杜绝运行时异常。
