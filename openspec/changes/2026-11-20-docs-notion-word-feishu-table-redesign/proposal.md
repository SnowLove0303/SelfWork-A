# Change: Notion/Feishu/Word Grade Table Architecture Redesign

## Why

用户给出了极其深刻、尖锐且切中要害的技术与体验反馈：
> “第一，表格的内框线都没对齐或者有断点；第二 表格功能你可以借鉴一下word 和 notion以及飞书去做吗，可能不是做一对按键放旁边啊”

经过 **5-Whys 深度根因穿透**，查明本质问题：
1. **内框线断点与不对齐的物理根因**：旧代码在每行末尾强行插入了一个隐藏/透明的 `<td className="w-13 ... border-transparent">` 操作列，导致最后一列真实数据单元格的边框与操作列产生断裂豁口；边框采用分散的局部样式，未构建封闭的完整网格系统。
2. **堆砌按钮的体验缺陷 (AI Slop)**：在表格右侧常驻一排上下箭头、垃圾桶、橡皮擦，在表头常驻一排按钮，视觉粗糙简陋，破坏了文档纯净度；未遵循现代专业文档（Notion / 飞书 / Word）的沉浸式交互规范。

## What Changes

1. **彻底修复表格内框线对齐与消除断点 (REQ-1)**：彻底剔除每行末尾多余的操作列 `<td className="w-13">`，采用纯粹闭合边框架构（`border-collapse: collapse` 配合统一暗黑边框色 `rgba(255,255,255,0.08)`），确保所有水平线垂直线严丝合缝、完全对齐，绝无断点与豁口。
2. **Notion / 飞书式边框吸附插入微手柄 (REQ-2)**：废除常驻外挂按钮。鼠标悬停在两列垂直分割线上时浮现 16px 圆形微手柄（带 `+`），点击即在两列间插入列；悬停在两行水平分割线上时浮现圆形微手柄，点击即在两行间插入行；移开鼠标后瞬间隐形。
3. **飞书 / Notion 式单元格与行列上下文菜单 (REQ-3)**：在表格内任意单元格右键，弹出紧凑暗黑毛玻璃菜单，收敛文本对齐、行列插入、数据清空、删除行/列/表操作。
4. **Word 式键盘录入与自然文本选区 (REQ-4)**：优化 `Enter`（同列下移，末行自动加行）、`Shift+Enter`（单元格换行）、`Tab` 跳格。
