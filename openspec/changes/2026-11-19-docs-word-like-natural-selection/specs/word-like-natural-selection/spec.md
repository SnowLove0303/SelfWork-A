# 规格契约：Word 级自然选区与段落块辅助化 (Specification)

## 1. 规范概述
本规范确立文档编辑器在划选大片内容时的行为与渲染标准，严格遵循 RFC 2119 规范，消除段落块边界对文本流式选区的物理割裂与视觉干扰。

---

## 2. 行为与视觉契约 (RFC 2119)

### 2.1 消除外层卡片化轮廓 (De-cardify Selection)
- 系统 **SHALL NOT** 在段落外层容器（`id="block-{id}"`）上应用任何外边框（`ring`）、大圆角（`rounded-xl`/`rounded-lg`）或重度阴影；
- 系统 **SHALL NOT** 将段落左侧拖拽手柄留白区域、复选框外部区域以及右侧留白区域渲染为选中背景；
- 选区高亮 **SHALL** 精准下沉至实际文本内容所在的编辑容器（`contenteditable` 容器及其直接子树），贴合文字行排版。

### 2.2 Word 级文字流高亮质感 (Word-like Text-stream Highlight)
- 当段落处于跨块选中状态（`isCrossSelected === true`）时，系统 **SHALL** 为文本内容区域应用与暗黑模式深度契合的平平整整文本选区背景（如 `bg-sky-500/25` 或 `bg-[#264f78]`），无凸起边框、无圆角突刺；
- 编辑器正文全局 **SHALL** 配置统一的 `::selection` 高亮样式，确保单段内的原生文字拖选与跨段大选区在背景色调、文字对比度与视觉饱和度上达到像素级一致；
- 多个连续段落被选中时，行与行之间的视觉过渡 **SHALL** 保持自然顺畅，消除“一块块斑马卡片”的视觉割裂。

### 2.3 段落块辅助化与手势无阻断 (Blocks as Auxiliary)
- 在鼠标按住划选大片内容的过程中，段落块的悬浮拖拽手柄（`renderSideHandle`）**SHALL** 保持静默，不得抢占指针事件或阻断文字划选；
- 划选过程中鼠标从任意块划入相邻块时，系统 **SHALL** 保持连续稳定的选区更新，不得产生闪烁或选区漂移；
- 用户在文档任意非文本区域单击时，系统 **SHALL** 立即清空 `crossSelectedBlockIds`，恢复单点光标。

### 2.4 批量操作与数据无损契约 (Batch Operations Parity)
- 在大片内容选中状态下按下 `Ctrl+C` / `Cmd+C` 时，系统 **SHALL** 收集所选全部块的纯文本，并根据列表、代办、引用及代码块语义添加对应换行符，写入剪贴板；
- 在大片内容选中状态下按下 `Backspace` 或 `Delete` 时，系统 **SHALL** 执行原子批量删除，并保留单个空聚焦段落；
- 在大片内容选中状态下按下 `Escape` 时，系统 **SHALL** 立即退出多选模式。
