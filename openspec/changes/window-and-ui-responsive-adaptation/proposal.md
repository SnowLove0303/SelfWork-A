# Change Proposal: 窗口与 UI 全域弹性自适应与抗挤压重构 (window-and-ui-responsive-adaptation)

## 1. 变更背景与事实指纹
- **需求事实指纹**: `USER_PROMPT_SHA256: b174ebfc44351dc9cb440e92d77dea55bb102632b70c240c23ac6df2c3fd9db1`
- **用户原始需求**: `接下来要做窗口与UI 自适应，目前窗口缩放会导致UI与部分文字扭曲，你知道原因的`
- **核心痛点根因 (5-Whys)**:
  1. Flex 布局中子元素默认 `flex-shrink: 1`，未声明 `shrink-0` 的图标与操作按钮在窗口缩小时被无差别横向挤压变形；
  2. 文字容器缺少 `min-w-0` 与 `whitespace-nowrap`，导致标题与按钮文字被挤压成单字折行甚至重叠扭曲；
  3. 双栏工作台（启动器 55%:45%、待办便签 58%:42%）采用刚性硬编码百分比，缺乏最小安全宽度（Min-Width Boundary），窄视口下工具栏十余个控件挤压错乱；
  4. 缺乏桌面视口响应式断点与侧边栏联动策略，高分屏 125%/150% DPI 缩放场景下过早陷入空间极限。
