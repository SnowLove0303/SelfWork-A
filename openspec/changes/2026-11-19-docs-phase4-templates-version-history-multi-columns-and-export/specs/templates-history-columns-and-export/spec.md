# 规范契约：模板库、历史快照、多栏布局与高保真导出 (Spec)

## 1. 技术文档模板库规范 (Doc Templates Spec)
- **SHALL** 当文档处于空白初始状态（仅有 1 个空段落）时，在正文区标题下方渲染 4 个模板选择卡片：
  - 💡 技术方案设计规范 (RFC/Spec)
  - 🐞 Bug 深度复盘与 5-Whys 分析
  - 📅 研发周报与版本发布日志 (Changelog)
  - 📚 编程语言核心知识点卡片
- **SHALL** 点击任一模板卡片时，将文档块列表原子替换为对应模板的完整块流，并自动赋予连续递增的 `sortOrder`；
- **SHALL** 替换后自动触发持久化保存并隐藏模板选择区域。

## 2. 文档历史快照与时间轴回滚规范 (Doc History & Snapshot Spec)
- **SHALL** 每次文档保存时根据时间间隔（如间隔 > 60 秒或显著内容变化）自动沉淀一个版本快照；
- **SHALL** 提供手动“创建快照”入口，快照包含 `id`, `pageId`, `timestamp`, `blockCount`, `wordCount`, `blocks` 完整深拷贝；
- **SHALL** 点击顶栏“版本历史”按钮时，滑出右侧时间轴抽屉；
- **SHALL** 抽屉内清晰罗列时间轴、相对时间、块数与字数指标；
- **SHALL** 支持点击任一快照进行只读预览，并在顶部明确提示“当前正在预览历史版本”；
- **SHALL** 提供“恢复到此版本”按钮，恢复前自动对当前最新版本执行一次防御性备份，确保历史回滚零丢失。

## 3. 多栏排版布局规范 (Multi-Column Layout Spec)
- **SHALL** 支持通过快捷菜单 `/columns` 或新建块类型插入多栏排版块；
- **SHALL** 默认支持 **2 栏等宽**（`1:1`）与 **3 栏等宽**（`1:1:1`）模式自由切换；
- **SHALL** 各栏内容独立进行 contenteditable 编辑与实时更新；
- **SHALL** 支持在各栏内输入多行富文本；
- **SHALL** 当视口宽度缩窄时，自动折叠为纵向流动布局，杜绝水平横向溢出破版。

## 4. 独立 HTML 与打印/PDF 导出规范 (HTML & Print/PDF Export Spec)
- **SHALL** 顶栏导出菜单扩展为下拉菜单，提供：
  - 导出为 Markdown (`.md`)
  - 导出为独立 HTML (`.html`)
  - 打印 / 保存为 PDF (`window.print()`)
- **SHALL** 导出的 HTML 文件包含内嵌完整 CSS，可在外部任意现代浏览器独立阅读；
- **SHALL** 在 `@media print` 媒体查询中强制隐匿：侧边栏、标题栏、操作手柄、按钮、目录大纲、查找工具条与统计胶囊；
- **SHALL** 打印样式保留正文、标题呼吸间距、表格线框、图片与代码块完整展示。
