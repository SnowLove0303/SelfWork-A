# Proposal: 快速启动灵活多选启动与自定义持久化捆绑套件

## 1. 意图与背景 (Intent & Context)
用户在体验快速启动的“一键全启动”后提出核心诉求：
> “那个捆绑启动的功能呢，我需要能灵活选择同时启动我所选择的应用啊脚本啊之类，懂我意思吗？”

此前系统的“一键全启动”是无差别拉起分类下的全部项目，缺乏灵活性。用户需要：
1. **即时自由多选批量启动**：在大盘中随手勾选任意 2~3 个应用或脚本，一键同时拉起所选；
2. **持久化自定义捆绑套件**：支持把特定的多个应用与脚本打包成一个固定的“启动组合套餐”项，后续点击该卡片即可一次性同时唤醒套件内所有项目。

- 既有 `app` / `script` / `url` / `folder` 启动项单卡点击秒开交互 100% 保持；
- 用户已保存在 SQLite 中的所有分类与启动项数据 100% 零损耗平滑继承。
