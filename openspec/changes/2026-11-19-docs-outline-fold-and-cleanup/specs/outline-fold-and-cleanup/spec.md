# 规格契约：文档大纲展开按钮收敛与父子级标题折叠系统 (Specification)

## 1. 范围与定义

本规格定义 SelfWork 文档编辑器右侧目录大纲栏的单一唤出入口契约以及父子级标题折叠渲染契约。

## 2. 行为契约 (RFC 2119 标准)

### 2.1 展开按钮收敛契约 (REQ-TOC.1)

- **SHALL**: 系统 **SHALL** 彻底移除正文编辑容器内部悬浮常驻的右侧「大纲」胶囊按钮 (`absolute right-4 top-4 z-20`)。
- **SHALL**: 顶栏右侧的「目录大纲」按钮 **SHALL** 作为大纲显隐切换的唯一权威入口：
  - **WHEN** 大纲当前处于收起状态时：按钮 **SHALL** 显示为「展开目录大纲」并附带标题计数；点击时展开右侧大纲栏，并持久化更新 `selfwork_doc_outline_visible = "true"`；
  - **WHEN** 大纲当前处于展开状态时：顶栏按钮 **SHALL** 保持常驻且呈现激活高亮状态，点击时收起大纲栏，并持久化更新 `selfwork_doc_outline_visible = "false"`。
- **SHALL NOT**: 界面上 **SHALL NOT** 存在第二个相同功能的展开胶囊或悬浮手柄。

### 2.2 父子级标题折叠契约 (REQ-TOC.2)

- **SHALL**: 系统 **SHALL** 依据文档流中的线性标题序列动态推演父子归属关系：
  - H1 节点对其后出现的所有 H2/H3 拥有管辖权，直至遇到下一个同级或更高级标题（下一个 H1）；
  - H2 节点对其后出现的所有 H3 拥有管辖权，直至遇到下一个同级或更高级标题（下一个 H1 或 H2）；
  - H3 节点无子标题。
- **SHALL**: 凡是拥有至少一个子节点的父标题项，其左侧 **SHALL** 渲染一个独立的折叠微箭头指示图标：
  - **WHEN** 父节点处于展开状态时，渲染 `ChevronDown`；
  - **WHEN** 父节点处于折叠状态时，渲染 `ChevronRight`。
- **SHALL**: 点击折叠微箭头时：
  - 系统 **SHALL** 阻止事件冒泡 (`stopPropagation`)；
  - 系统 **SHALL** 切换该节点的折叠状态，受其管辖的子标题 **SHALL** 立即隐藏或显现；
  - 系统 **SHALL NOT** 触发正文编辑区的滚动穿梭跳转。
- **SHALL**: 点击标题项文本或主空白区域时：
  - 系统 **SHALL** 触发平滑滚动至对应标题块正文锚点 (`handleScrollToHeading`)。
- **SHALL**: 大纲顶栏 **SHALL** 提供一键「全部展开 / 全部折叠」快捷控制微操作，方便长文档全景切换。
- **SHALL**: 折叠机制 **SHALL** 与既有的「全部 / 仅H1 / H1+H2」过滤器完全兼容正交运行。
