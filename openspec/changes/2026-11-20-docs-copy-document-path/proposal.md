# 变更提案：新增文档路径复制功能 (Copy Document Path)

## 变更背景与需求来源
在用户日常组织与查阅文档过程中，经常需要在个人日志、任务卡片、外部沟通或跨篇笔记中引用或记录某一文档的层级归属。当前系统虽在顶部具备面包屑展示，但缺乏直接将文档完整层级路径快速提取至操作系统剪贴板的快捷能力，侧边栏列表中也无法快速提取目标文档的路径。用户明确提出：“需要做一个复制文档路径的功能”。

---

## 1:1 需求物理对账矩阵 (Requirements Traceability Matrix - RTM)

| 需求 ID | 用户原始诉求与核心场景 | 拟定技术实现方案 | 验收标准 (Acceptance Criteria) |
|---|---|---|---|
| **REQ-PATH-COPY.1** | **顶部导航栏一键复制路径**：在正在查阅/编辑的文档顶部，提供显式直观的“复制路径”操作入口 | 在 `DocsView.tsx` 顶部面包屑导航条右侧操作胶囊区增加“复制路径”按钮；同时支持点击面包屑文本直接一键复制 | 1. 顶部操作区展示带有 `Copy` 图标的“复制路径”按钮；<br>2. 点击面包屑文字或复制路径按钮，均可即时将全路径写入剪贴板；<br>3. 按钮状态在复制后即刻变为绿色勾选 `✓ 已复制路径` 并维持 1.8 秒后平滑复原。 |
| **REQ-PATH-COPY.2** | **侧边栏文档项快捷复制**：在左侧树状目录/文档列表中，无需打开文档即可快速提取其归属路径 | 在 `DocsView.tsx` 侧栏各文档项（`subPages`、私人根目录项、最近项等）的悬停操作按钮组中，增加微型 `Copy` 图标按钮 | 1. 鼠标悬停侧栏任意文档项时显示“复制路径”微按钮；<br>2. 点击该按钮直接复制该文档的全层级路径，不强行切换当前正在编辑的页面；<br>3. 按钮悬停提示包含清晰的 Tooltip：“复制文档路径”。 |
| **REQ-PATH-COPY.3** | **递归多级层级路径解析规范**：复制内容遵循规范的树状层级展开 | 实现 `getPagePath(p: DocPage, partitions: DocPartition[]): string` 纯函数，根据分区的 `parentId` 递归溯源，拼接为 `私人 / [子分区] / ... / [文档标题]` | 1. 根目录项输出：`私人 / [文档标题]`；<br>2. 嵌套子分区项输出：`私人 / 深度学习 / Python进阶 / 02.3 集合类型`；<br>3. 无标题文档自动回退为 `未命名笔记`，杜绝空字符串拼接异常。 |
| **REQ-PATH-COPY.4** | **触觉交互与轻量级 Toast 反馈**：提供清晰、不遮挡主视口的微交互反馈 | 当触发复制动作后，除了按钮瞬时状态切换外，在界面出具全局轻量级浮层微提示 Toast（例如 `✓ 已复制路径: 私人 / Python进阶 / 02.3 集合类型`），并在 1.8 秒后自然淡出 | 1. 复制触发时 100% 给予剪贴板写入与视觉确认双重保障；<br>2. 粘贴至外部记事本或编辑器，内容与提示严格一致。 |
