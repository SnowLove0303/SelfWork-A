# 变更提案：大纲栏「仅H1、H2」层级硬过滤彻底清除 (Proposal)

## 一、 需求溯源与问题根因

用户反馈：
> `这个仅H1、H2 啥的不要`
> 配发截图红框圈出大纲顶部的「全部 / 仅H1 / H1+H2」过滤胶囊组。

在已上线完善的智能多层级父子折叠树系统后，原有的机械层级硬过滤器已无实质价值，反而占用大纲顶部空间、造成控件堆砌与视觉干扰。彻底清除该组件能够显著释放大纲侧栏空间，还原纯粹极简的高质感文档导航。

## 二、 1:1 需求物理对账矩阵 (RTM)

| 需求编号 | 需求名称 | 契约重点 |
| :--- | :--- | :--- |
| **REQ-TOC-CLEAN.1** | **彻底清除大纲「仅H1、H2」过滤胶囊** | 彻底移除大纲顶部的 `outlineFilter` 状态及「全部 / 仅H1 / H1+H2」按钮组，大纲默认完整渲染多级树。 |
| **REQ-TOC-CLEAN.2** | **精致化融入一键「全部展开/全部折叠」** | 将一键全折叠/展开微操作优雅对齐于大纲头部右侧，保持多层级一键宏观折叠与独立微箭头折叠能力。 |

## 三、 拟变范围与影响半径

- 变更文件聚焦在 `src/components/docs/editor/BlockEditor.tsx`。
- 其他组件及跨块划选、排版呼吸感等绝对保持只读。
