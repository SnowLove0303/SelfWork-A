# 规格契约：大纲栏层级硬过滤彻底清除 (Specification)

## 1. 范围与定义

本规格定义 SelfWork 文档编辑器右侧大纲栏顶部过滤组件清除与全量树状大纲展示契约。

## 2. 行为契约 (RFC 2119 标准)

### 2.1 过滤胶囊彻底清除契约 (REQ-TOC-CLEAN.1)

- **SHALL**: 系统 **SHALL** 彻底移除大纲顶部的 `outlineFilter` 状态机与「全部 / 仅H1 / H1+H2」三个按钮元素。
- **SHALL**: 大纲目录列表 **SHALL** 默认全量展示所有层级的标题节点，仅受用户的主动父子折叠（`collapsedHeadingIds`）控制。
- **SHALL**: 大纲侧栏顶部 **SHALL** 释放垂直与水平空间。

### 2.2 全局折叠控制微操作契约 (REQ-TOC-CLEAN.2)

- **SHALL**: 大纲栏头部 **SHALL** 在存在父级章节时，提供优雅紧凑的一键「全部折叠 / 全部展开」微按钮。
- **SHALL**: 点击该按钮 **SHALL** 一键收拢所有包含子项的 H1 和 H2 章节，或一键全部展开，同时保留每个章节左侧微箭头的独立折叠展开能力。
