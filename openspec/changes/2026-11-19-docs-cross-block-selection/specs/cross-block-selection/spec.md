# 规格契约：文档跨块自然划选与批量操作协同系统 (Specification)

## 1. 范围与定义

本规格定义 SelfWork 文档编辑器支持类似 Microsoft Word 的跨块连续鼠标拖选、跨块内容复制、批量删除与无缝体验契约。

## 2. 行为契约 (RFC 2119 标准)

### 2.1 跨块自然鼠标划选契约 (REQ-CROSS.1)

- **SHALL**: 系统 **SHALL** 在正文编辑容器层监听鼠标左键的按压（`mousedown`）、移动（`mousemove`）与释放（`mouseup`）全流程。
- **SHALL**: 当鼠标在块 $A$ 内按下，并持续移动离开块 $A$ 进入块 $B$（无论是向下拖动还是向上逆向拖动）：
  - 系统 **SHALL** 激活跨块选区模式 (`crossSelectMode = true`)；
  - 系统 **SHALL** 动态计算从起始块到当前鼠标指针所在块之间的连续块集合 $[B_{\text{start}}, \dots, B_{\text{end}}]$；
  - 范围内的所有块 **SHALL** 即时呈现沉浸式连续深蓝微光选中背景 (`bg-sky-500/20 text-white rounded-lg selection-overlay`)，与 Word 划选视觉体验对齐；
- **SHALL NOT**: 鼠标在块间跨越移动时，选区 **SHALL NOT** 被截断或停滞在起始块内。
- **SHALL**: 单击正文任意空白处或单块内重新点击时，系统 **SHALL** 立即退出跨块选区模式并清除所有块的跨选高亮。

### 2.2 跨块批量复制契约 (REQ-CROSS.2)

- **SHALL**: 在处于跨块选中状态下，当用户触发复制操作（`Ctrl+C`、`Cmd+C` 或剪切 `Ctrl+X`）：
  - 系统 **SHALL** 捕获剪贴板复制事件；
  - 系统 **SHALL** 提取所有跨选块的纯文本内容，以自然换行符 (`\n`) 进行拼接；
  - 系统 **SHALL** 调用剪贴板接口将完整内容写入系统剪贴板；
  - 用户粘贴到记事本、代码编辑器或其他文档时，文本段落与列表格式 **SHALL** 100% 完整无损。

### 2.3 跨块批量删除与替换契约 (REQ-CROSS.3)

- **SHALL**: 在处于跨块选中状态下，当用户按下 `Backspace` 或 `Delete` 键：
  - 系统 **SHALL** 阻止浏览器默认可能导致的孤立空块行为；
  - 系统 **SHALL** 一次性批量删除所有被跨选的块；
  - 系统 **SHALL** 在删除位置自动保留一个聚焦的空段落块，并将光标置于其中，确保排版流平滑过渡；
- **SHALL**: 在跨块选中状态下，用户直接键入有效可见字符时，系统 **SHALL** 先行销毁选中的所有块，并将键入字符写入新建聚焦的段落块中。

### 2.4 单块原生编辑与跨块选区解耦契约 (REQ-CROSS.4)

- **SHALL**: 仅在鼠标按住并跨越不同块边界时才激活跨块模式；
- **SHALL**: 在单个块内部的正常打字、光标箭头穿梭、双击选词、三击选行 **SHALL** 保持既有单块原生速度与手感，完全不受跨块协同器干扰。
