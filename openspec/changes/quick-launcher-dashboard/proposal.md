# Proposal: Quick Launcher Dashboard and Telemetry Console

## 1. Context & Motivation
用户提出核心功能开发需求：将工作台首个核心模块【快速启动 (`launcher`)】打造为充满现代工业感与座舱科技感的**“仪表盘开关 + 实时执行报文控制台”**。
通过深度整合本机 `D:\应用研究\统一启动器`（`wll` / `Workflow-Launcher.ps1`）的所有交互指令与服务平台，为用户提供：
1. **左侧仪表盘开关阵列 (Dashboard Switchboard)**：按业务集群卡片化呈现常用办公套件、AI 协同套件、核心 Web 平台、局域网访问控制、飞书机器人、WSL 专区及自动签到工具，支持一键总控开关与独立子项拨动开关；
2. **右侧执行报文控制台 (Telemetry Log Console)**：实时流式回显 PowerShell 脚本与 CLI 执行报文，提供格式化日志级别标识、清屏与复制功能；
3. **Rust 微内核异步执行管道 (Tauri IPC Engine)**：在 Rust 后端提供安全的异步命令调用与 TCP 端口/进程巡检能力，保持前端界面丝滑无阻塞。
