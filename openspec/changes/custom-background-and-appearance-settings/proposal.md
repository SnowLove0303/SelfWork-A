# Proposal: Custom Background and Settings Center Appearance Module

## 1. Context & Motivation
用户提出核心个性化需求：
1. **主工作台自定义背景**：支持用户个性化背景展示，并提供“全视口贯穿”与“仅主工作台画板”两种作用域切换；
2. **可扩展设置中心架构**：在【设置】模块中建立结构清晰的子分类系统，首发高保真实现「外观与背景」配置面板；
3. **参数控制器矩阵**：提供背景类型（预设流光/本地上传/URL）、画板透明度、磨砂模糊度、深色防眩遮罩滑块及一键重置；
4. **实时渲染与持久化**：参数调节实时无延迟预览，本地自动持久化存储。

## 2. 1:1 需求物理对账矩阵 (Spec-Kit RTM)

| 需求编号 | 需求事实与目标定义 | 规范与实现方案 (RFC 2119) | 物理验收充要指标 [Measured] |
| :--- | :--- | :--- | :---: |
| **REQ-BG-01** | 主工作区与全视口双模背景切换 | 提供切换选项（Segmented Switch）：支持“仅主工作台画板”与“全视口贯穿”两种背景生效范围 | 点击切换选项，背景立即在主画板卡片与全屏底层之间平滑转移 |
| **REQ-BG-02** | 可扩展设置中心框架与「外观与背景」子页面 | 在【设置】模块中建立支持未来拓展的子分类架构，首发建立「外观与背景」高保真 UI 视图 | 点击侧边栏【设置】，主舞台呈现标准设置中心，子菜单首选「外观与背景」并展现全部控件 |
| **REQ-BG-03** | 背景参数调节控制器矩阵 | 提供背景源选择（预设流光 / 自定义本地图片 / 网络 URL）、画板透明度滑块（0%~100%）、模糊度滑块（0px~40px）、深色防眩遮罩暗度滑块（0%~80%）及一键重置 | 调整任一参数滑块，界面立即产生实时视觉反馈，数值与视觉状态精确同步 |
| **REQ-BG-04** | 即时无延迟渲染与状态持久化 | 参数变更时无卡顿响应，并自动将配置数据落盘至本地存储（localStorage / 状态树），重启 EXE 时自动读取还原 | 刷新页面或重启 `SelfWork.exe`，用户自定义背景及全部滑动条数值自动完美复原 |
| **REQ-BG-05** | 既有系统不变量与文字定帧守恒 | 严格保留微软雅黑字体、流体发光 SW Logo、44px 绝对平齐水平线、单边框主干、无黑框控制台 EXE 及点击文字零抖动特性 | 全功能静态检查与构建退出码 0，文字在任何背景下保持高对比度与绝对静止 |
