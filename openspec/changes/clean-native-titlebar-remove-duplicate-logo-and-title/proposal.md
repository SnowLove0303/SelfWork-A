# OpenSpec Change Proposal: clean-native-titlebar-remove-duplicate-logo-and-title

## 1. 需求背景与方案宗旨 (Problem & Purpose)
在将桌面应用恢复为 Windows 原生深色标题栏后，用户测试并提出明确的视觉优化意见：**“只取消顶部栏这个重复的SW工作台文字和logo吧，保留顶部这个拖拽区栏”**。

产生该问题的视觉根因在于：
- Windows 原生标题栏左侧默认渲染应用程序小图标及窗口标题（“SW工作台”）；
- 紧随其下方的左侧边栏顶端同样展示专属的流体发光 SW Logo 与“SW工作台”；
- 造成左上角垂直方向出现明显的“双图标、双名称”视觉双胞胎与信息冗余。

本变更将：
1. **保留顶部原生深色拖拽区栏**：继续保持 Windows 原生沉浸式深色标题栏，保留 100% 硬件级丝滑拖动、Aero Snap 贴靠、双击最大化与右上角原生三按键；
2. **清除顶部标题栏的图文杂质**：在系统级外壳中清空窗口标题文字，并通过 Win32 API 移除原生标题栏左侧的小图标，使顶部拖拽条变为完全纯净、深邃的极简黑带；
3. **品牌标识收敛**：让流体发光 SW Logo 与“SW工作台”品牌标识纯粹在侧边栏顶端单点独家呈现。
