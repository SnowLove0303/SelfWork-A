# Proposal: Tasks & Sticky Notes Dual-Column Workspace

## 1. Context & Motivation
继快速启动中心（调度仪表盘 + 真实巡检 + 单行极简几何）交付后，用户提出工作台第二大核心生产力模块的开发诉求：
「接下来开发代办清单和便签功能」。

经需求对账与架构研讨（方案 A 获批），本提案确立了**座舱级双栏协同看板架构**：
- **左侧 58%：GTD 待办清单工作台 (Tasks Dashboard)**：提供极速回车录入、状态生命周期管理（待办/进行中/已完成）、颜色自明优先级点标（高/中/低）、今日过滤与批量清理，满足用户结构化工作安排；
- **右侧 42%：灵感便签墙 (Sticky Memo Board)**：提供即时自由便签卡片流，支持就地编辑、置顶（Pin）、复制到剪贴板与微调冷色调卡片底色，满足用户非结构化临时备忘（IP、命令、凭据、闪念）；
- **本地优先（Local-First）持久化**：全量数据安全持久化至本地存储，免服务器依赖，随开随用，断网离线 100% 稳定。
