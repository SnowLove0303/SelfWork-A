# Change Proposal: mindmap-basic-editor

## 1. 摘要 (Summary)
根据用户指令并基于 Ps-openspec 手脚层 REA 逆向 Xmind.exe 成果，在 SW 工作台（SelfWork）中开发全新**思维导图模块**。
实现极简且高可用的思维导图画布与核心编辑功能：中心主题与多级分支树形渲染、键盘快捷键（Tab 建子节点、Enter 建同级节点、Delete 删分支、双击/回车原地编辑）、文本大纲与 JSON 基础输入输出格式互转，以及本地持久化长效记忆。同时坚决遵循用户“先给普通的输入输出分支功能等就行了，先不要有其他的功能”的收敛禁令，不引入任何多余视觉与样式冗余。

## 3. 关联影响分析 (Impact Analysis)
- **新增模块路由**：在 `ModuleId` 中引入 `'mindmap'`，在 `Sidebar.tsx` 中注册思维导图导航入口（带 GitFork 图标），在 `SlotContainer.tsx` 挂载 `MindMapView`。
- **既有模块保护**：快速启动（Launcher）与待办清单（Tasks）完全保持现状不变，零影响。
- **存储拓扑**：利用 `db_get_setting` / `db_set_setting` 在 SQLite 中保存键名为 `'selfwork_mindmap_data'` 的序列化数据，无需修改底层数据库 Schema。
