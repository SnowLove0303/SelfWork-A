# Specifications: 快速启动专属组合管理与全量一键启动体系

## 1. 组合专属创建与生命周期契约 (REQ-COMBO-01)

### 1.1 独立入口呈现
- 系统 **SHALL** 在快速启动右侧大盘顶部工具栏（`h-[49px]`）右侧动作区常驻提供独立显眼的 `[+ 组合]`（新建组合）按钮，使用专属 `Layers` 图标与醒目晶体材质，与常规的 `[新建项]` 并立。
- 点击 `[+ 组合]` 按钮时，系统 **SHALL** 呼出专为组合定制的“创建启动组合”面板，表单自动锁定 `type: 'bundle'`，并聚焦于组合名称输入框。

### 1.2 组合编辑与删除
- 针对已创建的组合卡片，系统 **SHALL** 提供“编辑组合”菜单，允许重新修改组合名称、调整归属分类及勾选增减成员项。
- 删除组合卡片时，系统 **SHALL** 仅清理该组合自身的元数据记录，**SHALL NOT** 连带删除该组合内部所包含的底层应用程序或脚本项。

---

## 2. 启动项多选装配与保存为组合契约 (REQ-COMBO-02)

### 2.1 组合成员挑选与防套娃
- 组合配置面板中，系统 **SHALL** 提取当前系统中类型为 `app`、`script`、`url`、`folder` 的全部可用基础项供用户勾选。
- 候选清单 **SHALL NOT** 包含类型为 `bundle` 的其他组合项，且在编辑现有组合时 **SHALL NOT** 包含其自身，彻底杜绝循环嵌套死循环。
- 面板中提供“全选 / 清空”辅助动作，并实时呈现“已选 N 项 / 共 M 项”精确统计。

### 2.2 多选模式一键“保存为组合”
- 当用户进入“多选启动”模式且已勾选 1 项及以上启动项时，系统 **SHALL** 在多选顶栏操作区呈现 `[保存为组合]` 动作按钮。
- 点击 `[保存为组合]` 时，系统 **SHALL** 立即呼出创建组合面板，并将当前用户勾选的所有项目 ID 预置为新组合的初始成员项，用户仅需录入组合名称即可秒级保存。

---

## 3. 组合视觉展示与“启动组合”调度契约 (REQ-COMBO-03)

### 3.1 组合卡片专属微观视觉呈现
- 组合卡片在网格大盘中 **SHALL** 具备专属视觉标识：
  - 顶部呈现 `组合·N项` 标签与专属玫瑰金/青蓝层叠光环；
  - 卡片中心呈现多层晶体图标及组合名称；
  - 卡片中下部呈现内含成员的微缩图标堆叠或成员名称摘要胶囊，让用户一览即知包含哪些应用；
  - 鼠标悬浮时底栏明确呈现带有播放箭头的 `[启动组合]` 唤起指引。

### 3.2 启动组合全量调度与安全微间隔
- 当用户点击组合卡片或“启动组合”时，系统 **SHALL** 顺序唤起该组合所绑定的所有子项。
- 每次唤起子项之间 **SHALL** 引入 150ms 的安全微间隔，避免 Windows 瞬间并发唤起多进程引发竞争或依赖动态库锁死。
- 系统 **SHALL** 实时更新浮动反馈消息（例如：`正在启动【每日办公】组合 (3/3): 微信, 飞书, Chrome...`），若某单个项目因本地路径失效失败，系统 **SHALL** 记录具体失败项目并继续唤起其余有效项，绝不全流程阻断。
