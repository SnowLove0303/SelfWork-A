# Proposal: 快速启动专属组合管理与全量一键启动体系 (Launcher Dedicated Combos & Group Launch)

## 一、 背景与动机 (Why)

在快速启动工作台中，虽然前期提供了即时多选启动模式，但用户在高频使用场景中（如每日固定上班打开“微信 + 飞书 + Chrome + Xmind”、或者开发时打开“Antigravity + 终端 + Edge + 调试脚本”）有着明确的“固定套件长期沉淀”诉求。用户明确指示：
> “现在有个多选启动还不够，我要的是，能够创建组合，可以将多个启动项添加进该组合中，然后我点击启动组合，可以启动对应组合中所有启动项”

需要将“组合 (Combo / Launch Group)”作为一等公民（First-Class Citizen）推向大盘，提供显式独立的“新建组合”入口、多选模式一键“保存为组合”、以及卡片大盘直观显眼的“启动组合”联动调度与成员预览。

## 二、 1:1 需求物理对账矩阵 (1:1 RTM Ingestion)

严格 1:1 守恒注入 Step 0 确立的三大核心法定需求：

| 需求编号 | 用户原始输入锚点 | 核心业务契约定义 |
| :--- | :--- | :--- |
| **REQ-COMBO-01** | “能够创建组合” | 顶栏提供常驻显式的 `[+ 新建组合]` 独立入口，支持一键打开“创建启动组合”面板，自定义名称、所属分类与生命周期管理（编辑/删除）。 |
| **REQ-COMBO-02** | “可以将多个启动项添加进该组合中” | 组合面板提供直观的可视化多选穿梭列表（含全选/清空/项数统计/原生图标回显）；并在“多选启动”模式下支持一键 `[保存为组合]`，自动将当前勾选项目固化为新组合。 |
| **REQ-COMBO-03** | “我点击启动组合，可以启动对应组合中所有启动项” | 组合卡片在大盘呈现独特的组合晶体层叠质感、成员项数角标与子成员微缩图标堆叠预览；卡片具备显眼的 `[启动组合]` 交互，点击后以 150ms 安全微间隔无遗漏唤起组合内所有成员并精准反馈状态。 |

## 三、 拟变范围与不变量契约 (Scope & Invariants)

- **拟变文件**：
  - `src/components/LauncherDashboard.tsx`（顶栏动作组、多选保存组合通道、专属组合创建/编辑模态框、组合卡片专属视觉与启动组合逻辑）
  - `CHANGELOG.md`（版本更新与防线沉淀）
- **承重墙绝对保全承诺**：
  - `src/components/Sidebar.tsx` 与 `src/components/Titlebar.tsx` 保持 0 修改；
  - 侧栏宽度 `w-64` 与顶标行 `h-[49px]` 基准线绝对严密对齐；
  - SQLite 数据库中用户已有的常用应用（微信、飞书、企业微信、Antigravity、Xmind 等 11 个应用及分类）100% 保全；
  - 纯净脱机单文件 EXE 离线协议架构保持完好。
