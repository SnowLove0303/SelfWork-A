# Technical Design: 快速启动专属组合管理与全量一键启动体系

## 1. 架构总览与交互流转 (Architecture Flow)

```text
┌────────────────────────────────────────────────────────────────────────┐
│                        快速启动顶部工具栏 (h-[49px])                   │
│  [多选启动]  [+ 组合] (新建组合专属入口)   [+ 新建项]   [搜索框]       │
└──────────────────────────────────┬─────────────────────────────────────┘
                                   │
               ┌───────────────────┴───────────────────┐
               ▼                                       ▼
  【常规创建组合】                         【多选模式一键固化】
  点击 [+ 组合] 按钮                       多选启动勾选 N 项 -> 点击 [保存为组合]
  呼出专用组合面板                         自动填充所选成员并呼出面板
               │                                       │
               └───────────────────┬───────────────────┘
                                   ▼
                   【组合配置面板 (Combo Modal)】
                   • 组合名称 (如：每日办公全套)
                   • 所属分类下拉选择
                   • 成员应用/脚本复选穿梭 (带图标、防套娃、全选/清空)
                                   │
                                   ▼ 提交保存
┌──────────────────────────────────┴─────────────────────────────────────┐
│                       大盘网格中的【组合卡片】 (Combo Card)            │
│  • 顶部：`组合·N项` 专属徽标                                           │
│  • 中部：多层晶体图标 + 组合名称                                       │
│  • 摘要：内含子项原生微缩图标重叠渲染 (Icon Stack)                      │
│  • 底栏：悬浮呈现显眼的 [▶ 启动组合] 按钮                              │
└──────────────────────────────────┬─────────────────────────────────────┘
                                   │ 点击卡片或 [启动组合]
                                   ▼
                   【安全调度管线 (Safe Dispatcher)】
                   • 解析组合 bundleItemIds
                   • 依次执行 launch_custom_target / execute_custom_script
                   • 每项步进间隔 150ms 缓冲
                   • 实时更新 Toast: "正在启动【XXX】(i/N): AppName..."
```

## 2. 状态机模型设计 (State Machine Extensions)

在 `src/components/LauncherDashboard.tsx` 扩展状态机：
1. `isComboModalOpen: boolean`：独立控制组合创建与编辑弹窗，彻底将组合创建体验从复杂通用的单项弹窗中解耦；
2. `editingComboItem: LauncherItem | null`：当前正在编辑的组合对象；
3. `comboFormName: string` / `comboFormCategoryId: string` / `comboFormItemIds: string[]`：组合专用表单受控状态；
4. `handleOpenCreateComboModal(initialItemIds?: string[])`：
   - 当从顶栏 `[+ 组合]` 触发时：`initialItemIds = []`；
   - 当从多选模式 `[保存为组合]` 触发时：`initialItemIds = selectedItemIds`，自动完成所选项的初始勾选，省去用户二次挑选成本。

## 3. 组合卡片视觉设计规范 (Visual Hierarchy & Anti-AI-Slop)

- **尺寸锁定**：保持与其他卡片相同的 `h-36` 规整尺寸与紧凑间距，网格对齐零破损；
- **材质质感**：采用微透青蓝+紫晶渐变辉光边框（`hover:border-cyan-400/60 shadow-[0_0_15px_rgba(6,182,212,0.15)]`）；
- **成员缩略堆叠 (Avatar Stack)**：
  - 在卡片中央下方，以负边距（`-space-x-1.5`）重叠渲染前 4 个子项的 16x16 微缩原生高清图标，并在右侧附上 `+K` 或项数标签；
  - 直观传达“组合”的容器与复合属性，用户无需进入设置即可清晰预知点击后会拉起哪些软件；
- **操作明确性**：悬浮时底栏突出显示 `[▶ 启动组合]`，彻底消灭交互歧义。
