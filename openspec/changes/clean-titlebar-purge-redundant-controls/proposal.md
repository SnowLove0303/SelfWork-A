# OpenSpec Change Proposal: clean-titlebar-purge-redundant-controls

## 1. 需求背景与方案宗旨 (Problem & Purpose)

在完成统一深色控制台顶栏初版重塑后，用户经过实际体验提出了精准的界面减噪与精简指令：
1. **顶部不要再加导航栏折叠展开功能，有一个就够了**：
   - 侧边栏本身已具备专属的折叠与展开控制按钮；
   - 顶部栏再次放置折叠展开按钮造成了“一屏两个折叠键”的功能堆砌与视觉干扰；
   - 必须彻底移除顶部栏左侧的折叠展开按钮，仅保留侧边栏原有的收展机制。
2. **移除 Desktop 状态显示**：
   - 顶部栏右侧常驻的“Desktop / Web Preview”状态探测胶囊属于技术性调试/连接信息，在日常专注使用时形成不必要的视觉杂音；
   - 必须彻底从顶栏右侧移除该胶囊及状态指示灯。
3. **重新调整顶栏布局排版**：
   - 在剥离上述两处多余控件后，重新规划顶栏空间分布：
     - 左侧：纯粹以 `#E6EDF7` 主标题“SW工作台”为锚点，紧凑对齐模块名与说明（`#8FA3BF`），呈现干净洗练的现代工具排版；
     - 中间：最大化释放物理拖拽抓手区域（`data-tauri-drag-region`），支持硬件级顺畅拖动与双击最大化；
     - 右侧：纯粹保留极简细线条窗口控制三按键（最小化、最大化/还原、克制暗调且悬浮柔和暗红的关闭按钮）。
