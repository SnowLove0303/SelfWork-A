# 规范契约：反向链接、嵌入目录、局部图谱与键盘位移 (Spec)

## 1. 双向反向链接底栏规范 (Backlinks Panel Spec)
- **SHALL** 动态检测当前工作区中所有其他文档对当前文档 ID 的引用（包含 `#/page/{pageId}` 超链接）；
- **SHALL** 当检测到反向引用存在时，在正文区域最底端（新增段落按钮下方）渲染「反向链接」折叠卡片；
- **SHALL** 反向链接卡片显示：来源文档图标、标题、更新时间，以及引用段落的纯文本上下文；
- **SHALL** 点击任一反向链接卡片时，触发 `onNavigatePage(sourcePageId)` 跳转并激活目标页面。

## 2. 正文内嵌动态目录卡片规范 (TOC Block Spec)
- **SHALL** 支持通过快捷指令 `/toc` 插入类型为 `'toc'` 的块；
- **SHALL** 动态提取当前文档除自身之外的所有 H1、H2、H3 标题，渲染带有层级缩进（H1: 0px, H2: 12px, H3: 24px）的大纲树；
- **SHALL** 当正文各级标题发生内容变更或增删时，实时联动刷新目录树项；
- **SHALL** 点击任一目录项平滑滚动至对应标题位置；
- **SHALL** 挂载 6 点通用侧柄，支持整体拖拽重排与删除。

## 3. 局部文档关联力导向图谱规范 (Local Graph View Spec)
- **SHALL** 在右侧大纲抽屉顶部增设「大纲 (TOC)」与「图谱 (Graph)」双选项卡；
- **SHALL** 切换至「图谱」时，以当前文档作为高亮中心节点，向外辐射连接所有引用的目标页面与反向引用的来源页面；
- **SHALL** 连线清晰标注关系箭头或区分出度与入度；
- **SHALL** 节点支持物理拖拽、弹簧动力学阻尼自平衡与平移缩放；
- **SHALL** 双击任意周边节点立即跳转至对应文档。

## 4. 键盘流快速上下交换块规范 (Keyboard Swap Blocks Spec)
- **SHALL** 在任意块的编辑输入框中监听 `Alt + ArrowUp` 与 `Alt + ArrowDown`；
- **SHALL** 当触发 `Alt + ArrowUp` 且当前块非首块时，当前块与上方块原子交换顺序并更新 `sortOrder`；
- **SHALL** 当触发 `Alt + ArrowDown` 且当前块非尾块时，当前块与下方块原子交换顺序并更新 `sortOrder`；
- **SHALL** 交换后保持当前编辑块焦点与光标，免去鼠标点击；
- **SHALL** 自动压入 Undo 栈，支持 `Ctrl+Z` 恢复原序。
