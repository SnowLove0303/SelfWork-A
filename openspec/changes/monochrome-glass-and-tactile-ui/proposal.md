# Proposal: Monochrome Frosted Glass and Tactile UI

## 1. Context & Motivation
用户提出界面美学与交互质感升级需求：全面引入**黑灰白透明磨砂玻璃材质（Monochrome Frosted Glass / Glassmorphism）**并大幅提升**按钮与交互控件的微物理触觉质感（Tactile Interaction）**。
本变更旨在吸纳 Raycast、Linear.app 及顶级现代暗色桌面 UI 的工程实践，为 SW 工作台打造深邃通透的黑灰白空间层级与极具确定性的机械下压触觉反馈。

## 2. 1:1 需求物理对账矩阵 (Spec-Kit RTM)

| 需求编号 | 需求事实与目标定义 | 规范与实现方案 (RFC 2119) | 物理验收充要指标 [Measured] |
| :--- | :--- | :--- | :---: |
| **REQ-GLASS-01** | 黑灰白极简工业调色板 | 全局主色调收敛为克制的黑、灰、白多阶透明度梯度，消除不必要的杂色干扰 | 界面主背景、文字、线条均严格遵循黑灰白阶梯，对比度满足 WCAG 2.2 AA 规范 |
| **REQ-GLASS-02** | 半透明磨砂毛玻璃材质 | 侧栏、顶栏、主工作台画板及浮层卡片应用半透明亚克力磨砂质感 (`backdrop-blur`) 与微透深色底 | 视口具有通透层次景深，背透模糊效果柔和均匀，文字与图标清晰锐利不失真 |
| **REQ-GLASS-03** | 按钮微物理触觉质感 | 为侧栏导航按钮、功能操作项及状态胶囊引入内切光泽 (`inset 0 1px 0`) 与真实机械按压反馈 (`active:scale-[0.97]`) | 按钮在 Hover 时有轻微浮起/光泽提亮，Active 按压时有物理缩放下压与投影收敛手感 |
| **REQ-GLASS-04** | 全局模块材质协调一致 | 顶部状态栏、左侧导航栏、主舞台视口与控制控件的材质语言无缝呼应，保持严谨网格衔接 | 各组件间透明度阶梯自然衔接，交界线规整利落，无局部突兀或粗糙感 |
| **REQ-GLASS-05** | 既有功能与品牌特征保持现状 | 100% 保持微软雅黑字体、用户发光 SW 品牌 Logo、侧栏无闪烁折叠展开交互及免黑框 EXE 特性 | 变更前后核心业务功能、字体、Logo 渲染及打包体积无退化 |
