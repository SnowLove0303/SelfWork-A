## 2. 状态机转移设计 (State Machine)
- **ActiveViewMode**:
  - `TableFull`: 纯表格全屏浏览模式
  - `TableSidePeek`: 表格 + 右侧抽屉分屏联动模式 (Split 50%:50%)
  - `PageFull`: 抽屉一键全屏最大化为纯文档编辑模式
- **Row-Page Dual Sync**:
  - `DbCollectionRow.cells[colId]` $\leftrightarrow$ `DocPage.properties[colId]` 内存双向绑定，任何一方触发更新，同时提交 SQLite `db_save_collection_row` 与 `db_save_page`。

## 3. SQLite DDL 增量设计
- 新增 `doc_partitions` 表：
  ```sql
  CREATE TABLE IF NOT EXISTS doc_partitions (
      id TEXT PRIMARY KEY,
      name TEXT NOT NULL,
      partition_type TEXT NOT NULL, -- 'private' | 'favorite' | 'workspace'
      sort_order REAL NOT NULL,
      is_collapsed INTEGER NOT NULL DEFAULT 0,
      created_at INTEGER NOT NULL,
      updated_at INTEGER NOT NULL
  );
  ```
- `doc_pages` 增加 `partition_id TEXT DEFAULT 'private'`, `parent_id TEXT`
- `db_collections` 增加 `partition_id TEXT DEFAULT 'private'`, `parent_id TEXT`
