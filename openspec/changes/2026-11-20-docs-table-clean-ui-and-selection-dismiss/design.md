# Design: Docs Table Clean UI and Instant Selection Dismiss

## 1. 架构总览与选区解耦设计 (Architecture Overview)

针对“表格一选中就无法退出选中”以及“抬头按钮说明过多太杂”的问题，本设计对选区生命周期与界面层级进行双重重构：

```text
┌────────────────────────────────────────────────────────────────────────┐
│                   【Selection Lifecycle Statechart】                   │
│                                                                        │
│   [Normal Input State]                                                 │
│            │                                                           │
│            │ (Shift+Click OR Drag across cells)                        │
│            ▼                                                           │
│   [Multi-Cell Range State] ──(Single Click on any cell)──► [Normal]   │
│            │                                                           │
│            ├──(Click outside table container)───────────► [Normal]     │
│            │                                                           │
│            └──(Press Escape key anywhere)───────────────► [Normal]     │
└────────────────────────────────────────────────────────────────────────┘
```

---

## 2. 界面极致净化 (Visual Decluttering & Zero-Chrome)

### 2.1 移除抬头与底部废话堆砌
- **彻底剔除**:
  - 抬头平铺的 `[对齐]`、`[底纹]`、`[斑马纹]`、`[表头]`、`[复制 MD]`、`[删除整表]` 密集按钮条；
  - 底部“Word 9宫格对齐 · 莫兰迪底纹 · 右键 Mini Toolbar · Shift+点击/拖拽跨行跨列多选”说明文字；
- **重构为极简头部**:
  - 仅保留极简柔和的 `数据表格 · N列 × M行` 标签；
  - 悬停时右上角仅显式提供一个低调的 `···` 快速呼出右键菜单的入口（或删除按钮）。

### 2.2 全功能收敛至右键上下文菜单 (`TableContextMenu`)
