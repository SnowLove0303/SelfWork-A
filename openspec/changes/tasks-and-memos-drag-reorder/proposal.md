# OpenSpec Change Proposal: tasks-and-memos-drag-reorder

## 1. 需求背景与方案宗旨 (Problem & Purpose)

当前 SW 工作台的“待办清单”与“灵感便签”功能已完成 SQLite 数据库持久化水合与基础 CRUD 交互，但在任务编排与便签归类场景下，用户希望能够自由拖拽调整待办与便签的前后次序：
1. **待办清单拖拽换位**：
   - 用户需要能够对任意待办事项进行抓取，上下平滑拖动至目标位置完成插入换位；
   - 拖拽过程中提供清晰的高亮插入线与卡片浮动半透明预览，操作结束后即刻更新任务排序。
2. **灵感便签卡片拖拽换位**：
   - 用户在便签墙上记录了多个点子与备忘，需要按重要程度或业务逻辑直接拖拽便签卡片换位；
   - 支持卡片拖拽至目标位置前/后，排序即时生效。
3. **交互手感与防误触隔离**：
   - 拖拽交互必须与已有的点击与编辑操作严格物理隔离；
   - 点击待办复选框、切换优先级微光点、在便签标题/内容文本框内打字编辑、点击复制、删除、置顶、调色盘等操作 100% 独立生效，绝对不被拖拽事件拦截误吞。
4. **实时持久化与冷启动无损记忆**：
   - 拖拽换位更新内存状态后，自动触发现有的 SQLite 300ms 防抖持久化管道（`saveTasks` / `saveMemos`）；
   - 应用重启或页面刷新后，自定义排列顺序 100% 完美恢复。
