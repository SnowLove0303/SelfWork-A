# Technical Design: Mindmap Top Toolbar Buttons Purge & Immersive Layout

## Architecture Overview
本设计旨在根据用户“先不要按钮，用快捷键就行”的明确指令，移除思维导图顶部的按钮工具栏，将主视口转换为 100% 垂直满高的高沉浸度画布。

```text
┌──────────────────────────────────────────────────────────────┐
│ SW工作台 - 主视口                                            │
├─────────────┬────────────────────────────────────────────────┤
│ 侧边栏导航  │ 思维导图视口 (MindMapView)                     │
│ (完全保持原样)│ ┌────────────────────────────────────────────┐ │
│ - 快速启动  │ │                                            │ │
│ - 待办清单  │ │          [思维导图满高画布 Canvas]          │ │
│ - 思维导图  │ │                                            │ │
│             │ │   (中心主题) ─── (分支主题) ─── (子分支)   │ │
│             │ │                                            │ │
│             │ │                                            │ │
│             │ │ ┌──────────────────────────────────────┐   │ │
│             │ │ │ 底部快捷键提示条 (Tab/Enter/Delete/编辑)│   │ │
│             │ │ └──────────────────────────────────────┘   │ │
│             │ └────────────────────────────────────────────┘ │
└─────────────┴────────────────────────────────────────────────┘
```

## Implementation Strategy
1. **视口结构优化 (`src/components/MindMapView.tsx`)**:
   - 彻底移除 `<MindMapToolbar ... />` 的渲染；
   - 移除 `MindMapView` 中多余的导入导出模态框触发状态与对 `MindMapToolbar` 的绑定；
   - 让 `<MindMapCanvas />` 容器直接作为 `MindMapView` 的主体，占据全部 `h-full w-full`，消除 44px 的顶部边框与留白割裂；
   - 保留左下角极简触觉快捷键指南指示条（Tab 子分支、Enter 同级分支、Delete 删除、双击/空格 改名），为用户提供清晰的视觉锚点。

2. **快捷键状态机保全 (`handleGlobalKeyDown`)**:
   - 键盘事件监听与调度逻辑保持不变，确保文本输入框聚焦时放行输入、非输入状态下拦截 `Tab` / `Enter` / `Delete` / `Backspace` / `Space` / `F2`；
   - 保证焦点与编辑状态无缝切换。

3. **依赖与文件保留 (`MindMapToolbar.tsx` / `MindMapIOModal.tsx`)**:
   - 保留 `MindMapToolbar.tsx` 与 `MindMapIOModal.tsx` 源码文件作为后续高级功能扩展储备，仅在当前主视图中不挂载，控制爆炸半径最小化。
