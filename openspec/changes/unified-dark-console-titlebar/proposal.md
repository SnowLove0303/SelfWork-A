# OpenSpec Change Proposal: unified-dark-console-titlebar

## 1. 需求背景与方案宗旨 (Problem & Purpose)

用户对当前 SW 工作台最顶部栏提出了深刻且细致的视觉优化要求：
1. **左上角突兀占位小图标问题**：
   - 现存的左上角小图标尺寸局促、干扰感强，缺乏与现代化深色科技界面的整体感；
   - 具有强烈的“临时系统占位”痕迹，破坏了顶栏的完整美感；
   - 需彻底移除该占位式小图标，并重构左侧区域排版，确保对齐与视觉平衡。
2. **顶部栏色彩脱节与割裂问题**：
   - 当前顶部栏在明度、质感与配色上与主页面脱节，呈现出独立的“系统默认窗口栏”外挂感；
   - 主体页面采用偏深色、科技感、冷静克制的深邃控制台设计语言，顶部栏需与其深度融入，形成统一、协调、有层次的整体视觉；
   - 需确立明确的深色控制台色彩体系：
     - 背景色：比主页面背景略显微蓝灰的深色（`#0B1220` / `#0D1422` / `#101826`）；
     - 边界分隔线：低存在感弱冷色描边 `rgba(80, 140, 200, 0.15)`；
     - 文字色彩阶梯：主标题采用高亮浅色 `#E6EDF7`，次级信息采用沉稳弱化色 `#8FA3BF`；
     - 交互反馈色：Hover 深蓝灰微提亮，Active 青蓝高亮联动；
     - 窗口关闭按钮：日常克制，Hover 呈现柔和暗红。
3. **架构整合与全域贯通**：
   - 将顶部栏提升为贯穿全窗体宽度的沉浸式顶级控制台栏（Full-width Unified Titlebar）；
   - 下部衔接左侧纯净功能导航侧栏与右侧主画布舞台，彻底消除侧栏顶部与顶栏的拼接缝隙；
   - 保留 100% 顺畅自然的物理拖拽交互（基于原生 `data-tauri-drag-region` 驱动，零 JS 异步阻塞）、双击最大化与完整的窗口控制能力。
