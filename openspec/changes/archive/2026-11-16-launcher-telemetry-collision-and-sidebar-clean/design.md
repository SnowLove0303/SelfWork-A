## 2. 核心技术改造点

### 2.1 执行报文默认状态与容器层级解耦 (`LauncherDashboard.tsx`)
- **状态收敛**：`const [isTelemetryOpen, setIsTelemetryOpen] = useState<boolean>(false);`，将默认开启改为默认收起，日常状态下工作区拥有 100% 完整横向空间。
- **浮动抽屉解耦**：
  为右侧大盘主容器赋予 `relative` 定位；将原平级挤占空间的静态 flex 子节点重构为绝对定位抽屉：
  ```tsx
  {isTelemetryOpen && (
    <div className="absolute right-0 top-0 bottom-0 z-30 w-[340px] xl:w-[400px] h-full flex flex-col overflow-hidden bg-slate-950/95 backdrop-blur-2xl border-l border-white/10 shadow-[-12px_0_30px_rgba(0,0,0,0.7)] animate-in slide-in-from-right duration-200">
      <TelemetryPanel
        logs={logs}
        onClearLogs={handleClearLogs}
        onClose={() => setIsTelemetryOpen(false)}
      />
    </div>
  )}
  ```
  - **优势**：
    1. 打开时不会触发父容器 Flex 重新分配空间，中间主工具栏宽度 100% 保持不动；
    2. “+ 新建项”按钮永远保持其完整文字与图标，绝对不被压缩成只有“+”号的残缺态；
    3. 报文面板自带高斯模糊与暗色阴影，层次感高级，关闭时立刻完全消失。

### 2.2 彻底剔除左下角版本信息 (`Sidebar.tsx`)
- 剔除 `Sidebar.tsx` 最下方的代码片段：
  ```tsx
  <div className="p-2 border-t border-border-default/40 flex items-center justify-center">
    <span ...>v0.1.0-alpha</span>
  </div>
  ```
- 导航列表 `nav.flex-1` 自然贴底，保持无缝玻璃流光体验。
