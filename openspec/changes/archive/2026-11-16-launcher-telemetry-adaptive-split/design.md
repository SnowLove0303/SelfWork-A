# Design: 快速启动执行报文并列协同布局与大盘卡片自适应重排

## 架构因果拓扑与几何响应式设计

### 1. 布局拓扑重构 (Flex Side-by-Side Invariant)
原方案中，执行报文采用了 `absolute right-0 top-0 bottom-0 z-30`，虽然避免了主视口的回流，但在小窗口或标准窗口下，由于其具备 340px 宽度且具有不透明/模糊背景，浮空直接覆盖了快速启动主大盘右半侧的内容（包括顶栏操作按键和最右侧的卡片）。

新方案回归 Flex 协同并列架构：
```text
┌────────────────────────────────────────────────────────────────────────────────────────┐
│ <LauncherDashboard> (flex-1 flex overflow-hidden)                                     │
├────────────────────┬───────────────────────────────────────────┬───────────────────────┤
│ 分类导航侧栏        │ 快速启动主大盘 (flex-1 min-w-0 flex flex-col)│ 执行报文协同面板       │
│ w-44 xl:w-52       │                                           │ (isTelemetryOpen)     │
│ (shrink-0)         │ ┌───────────────────────────────────────┐ │ w-[290px] xl:w-[350px]│
│                    │ │ 顶部工具栏 (h-[49px] shrink-0)        │ │ shrink-0 h-full       │
│                    │ │ [分类名] [搜索框] [多选] [全启] [+组] [+] [报文]│ │ border-l border-w/10│
│                    │ └───────────────────────────────────────┘ │                       │
│                    │ ┌───────────────────────────────────────┐ │ 实时滚动日志列表...    │
│                    │ │ 启动项卡片大盘网格 (overflow-y-auto)   │ │                       │
│                    │ │ repeat(auto-fill, minmax(136px, 1fr)) │ │                       │
│                    │ │ [添加] [微信] [Antigravity] [Ficlash] │ │                       │
│                    │ │ [Xmind] [企微] [Notion] [ChatGPT] ... │ │                       │
│                    │ └───────────────────────────────────────┘ │                       │
└────────────────────┴───────────────────────────────────────────┴───────────────────────┘
```

### 2. 响应式几何保障矩阵
1. **主大盘自适应机制**：
   - 主大盘容器配置 `flex-1 min-w-0 flex flex-col overflow-hidden`；
   - 当报文面板展开时，主大盘自然收缩 290px~350px；
   - 卡片网格的 `repeat(auto-fill, minmax(136px, 1fr))` 机制在宽度减小时，瞬间计算出新的最佳列数（例如从 5 列收缩为 3 列或 4 列），卡片向下折行流式排列，没有任何一张卡片被遮挡或裁切。
2. **顶栏工具链防挤压机制**：
   - 搜索框设为 `w-28 sm:w-36 md:w-44 min-w-[70px] shrink`，在空间充裕时舒展，在空间有限时自适应微缩；
   - 动作按钮统一携带 `whitespace-nowrap shrink-0` 与紧凑微边距 `gap-1 sm:gap-1.5`，确保文字在任何紧缩状态下均不被截断、不折行成单字；
   - 动作容器具备 `overflow-x-auto no-scrollbar` 兜底，极端微缩窗口下依然可以横向微滑交互。
3. **分类侧栏微调**：
   - 将左侧分类侧栏从 `w-48 lg:w-56` 适度微调为 `w-44 lg:w-52`，为中间大盘额外释放 16px~32px 黄金排版宽度，使得窗口化状态下并列展现更加游刃有余。
