# Design: 快速启动卡片排版极简与去噪设计

## 1. 结构变更前后拓扑对比

### 1.1 顶栏操作区
```text
[变更前]:
[多选 (暗晶)] [全启动 (暗晶)] [分屏组合 (暗晶)] [+ 新建项 (亮青实体高光)] [执行报文 (暗晶)]

[变更后]:
[多选 (暗晶)] [全启动 (暗晶)] [分屏组合 (暗晶)] [+ 新建项 (暗晶·青色+)]   [执行报文 (暗晶)]
```
