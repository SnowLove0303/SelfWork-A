# Proposal: 快速启动全局按钮设计体系与调色板收敛重构

## Why

快速启动台（Launcher）在经历多轮功能快速迭代后，顶栏操作群与卡片区域积累了显见的视觉风格割裂与调色盘碎片化问题（如用户截图标注）：
1. **调色盘水果糖杂色混杂**: 顶栏右侧按钮群同时并存青色（多选）、绿色（全启动）、粉红色（分屏组合）、深灰色（新建项）四种互不相干的色彩，造成视觉噪点过载；
2. **操作主次层级倒挂**: 核心最高频的 `[+ 新建项]` 操作呈现为最暗淡的深灰色，而辅助/低频操作反而用了高饱和背景色；
3. **分屏套件局部突兀**: 置顶分屏专区大面积采用 `rose-500`（粉红）调色，与系统整体的科技青蓝暗色玻璃拟态脱节；
4. **几何公差微跳动**: 各按钮之间的高度、内边距与圆角尺度未严格通过 Design Tokens 锁死。

## What Changes

1. **确立三级按钮体系 (Button Hierarchy Tokens)**:
   - **Primary Action (首选焦点)**: `[+ 新建项]` 升级为科技青实体发光按钮，成为顶栏绝对主行动点；
   - **Secondary Ghost (暗晶体次级按钮)**: `[分类]`、`[多选启动]`、`[全启动]`、`[分屏组合]`、`[>_ 执行报文]` 统一采用半透明深色玻璃质感（`bg-white/[0.04]` + `border-white/10` + `text-slate-300`，悬浮时 `hover:bg-white/[0.08]` + 科技微光）；
   - **Tertiary / Inline (嵌入微操作)**: 菜单触发、行内删除等保持极简轻量。
2. **调色板降噪与主品牌色收敛**:
   - 收敛为“一主品牌色（科技青 Cyan）+ 中性深灰玻璃（Slate Glass）”；
   - 绿色仅在运行/成功动态时点缀，红色仅在危险/删除时点缀，杜绝常驻彩色大底色涂鸦。
3. **分屏套件专区视觉融入全局暗晶体**:
   - 将置顶分屏专区背景板升级为深邃暗夜磨砂晶体（`bg-white/[0.02]` + `border-white/10`），套件启动按钮采用青蓝微渐变实体按钮。
4. **几何尺度与基线对齐**:
   - 统一高度为 `32px (h-8)`，基线与搜索框绝对对齐；
   - 统一圆角为 `12px (rounded-xl)`，图标统一为 `14x14px`。
