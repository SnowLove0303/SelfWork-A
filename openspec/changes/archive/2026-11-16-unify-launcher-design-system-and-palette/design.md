# Design: 快速启动按钮与调色板设计系统令牌架构

## 1. 按钮设计令牌矩阵 (Button Tokens Matrix)

```text
┌──────────────────────────────────────────────────────────────────────────────────┐
│                             按钮体系 Design Tokens                               │
├───────────────────┬──────────────────────────────────┬───────────────────────────┤
│ 等级 (Tier)       │ 视觉规格 (Tokens)                │ 应用代表组件              │
├───────────────────┼──────────────────────────────────┼───────────────────────────┤
│ Tier 1: Primary   │ h-8 rounded-xl px-3              │ [+ 新建项]                │
│ (全局主焦点)      │ bg-cyan-500 hover:bg-cyan-400    │                           │
│                   │ text-slate-950 font-semibold     │                           │
│                   │ shadow-[0_0_16px_rgba(6,182,212, │                           │
│                   │ 0.35)]                           │                           │
├───────────────────┼──────────────────────────────────┼───────────────────────────┤
│ Tier 2: Secondary │ h-8 rounded-xl px-2.5            │ [分类]                    │
│ Ghost (暗晶体)    │ bg-white/[0.04] hover:bg-white/  │ [多选启动]                │
│                   │ [0.08] border border-white/10    │ [全启动]                  │
│                   │ text-slate-300 hover:text-white  │ [分屏组合]                │
│                   │ hover:border-cyan-500/30         │ [>_ 执行报文]             │
├───────────────────┼──────────────────────────────────┼───────────────────────────┤
│ Tier 3: Tertiary  │ 极简图标按钮 p-1 rounded-lg      │ 更多菜单、行内删除        │
│ / Micro           │ text-slate-400 hover:bg-white/10 │                           │
└───────────────────┴──────────────────────────────────┴───────────────────────────┘
```

## 2. 调色板收敛映射 (Palette Convergence)

- **前**: `多选(cyan-500/10) + 全启动(emerald-500/20) + 分屏组合(rose-500/20) + 新建项(border-white/10)` 四色彩虹拼盘；
- **后**:
  - `新建项`: 升级为唯一的 `Primary` 实体发光按钮；
  - `多选 / 全启动 / 分屏组合 / 分类 / 执行报文`: 全部统一为标准的 `Secondary Ghost` 磨砂暗晶体；
  - 分屏套件卡片：边框从 `border-rose-500/30` 调整为 `border-white/10 hover:border-cyan-500/40`，背景由 `bg-rose-500/[0.03]` 调整为 `bg-white/[0.025]`；启动按钮调整为精致的 `bg-cyan-500/15 hover:bg-cyan-500/25 text-cyan-300 border border-cyan-500/30`。
