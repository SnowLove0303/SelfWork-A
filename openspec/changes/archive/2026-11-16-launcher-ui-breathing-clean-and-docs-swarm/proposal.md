# Proposal: 报文控制栏防溢出、顶栏呼吸空间重构、冗余文本剔除与文档表格 Swarm 派发

## Why
在快速启动与报文面板并列协同工作流落地后，用户在视觉与工程协同维度提出了四项明确的工业级体验改进：
1. **报文控制栏溢出**：报文面板顶栏操作按键群偏密，最右侧关闭按钮 `✕` 紧贴甚至微溢出容器右侧边框；
2. **按键呼吸空间不足**：顶栏按键与按键之间（如 `+ 组合`、`新建项`、`执行报文`）、按键与大盘左右边界之间空隙过紧，缺乏高端 UI 的舒展呼吸节奏；
3. **冗余底层说明**：报文面板底部展示的 `POWERSHELL IPC DAEMON READY UTF-8 / CREATE_NO_WINDOW` 属于底层开发调试信息，属于无效文本干扰，必须彻底清除；
4. **文档表格专属 Swarm**：设立专属的 Swarm Agent（`docs-table-worker`），后续全权负责“文档表格”（Notion 风格块级富文本编辑器、文档树、多维数据表格等）的功能开发与排版优化。

## What Changes
1. **报文终端操作栏防溢出与呼吸边距收敛 (`src/components/launcher/TelemetryPanel.tsx`)**:
   - 顶部控制栏增设 `px-3.5` 安全内边距与 `overflow-hidden` 容器硬约束；
   - 紧凑优化等级过滤胶囊（精简内边距与字阶）及功能图标组（`h-6 w-6`、`gap-1.5`）；
   - 确保最右侧关闭 `✕` 按钮与右侧边界保持至少 10px 舒适视觉间距，0 像素超出或被截断。
2. **顶栏工具链节奏与呼吸空间重塑 (`src/components/LauncherDashboard.tsx`)**:
   - 顶栏整体左右内衬扩展为 `px-4 md:px-5`，强化与左右边框的呼吸感；
   - 操作按键组间距优化为 `gap-2 sm:gap-2.5`，按键内部留白 `px-2.5 sm:px-3 py-1.5`，消除紧贴压迫感；
   - 建立视觉层次节奏：左侧分类信息、中间搜索输入框、右侧操作按键群秩序井然。
3. **彻底清除报文面板底部调试说明 (`src/components/launcher/TelemetryPanel.tsx`)**:
   - 彻底删除底部的 `POWERSHELL IPC DAEMON READY UTF-8 / CREATE_NO_WINDOW` 状态栏及对应容器；
   - 遵循 Radical Text Economy 极简少字原则，面板底部保持纯净无冗余文字。
4. **部署文档表格专属 Swarm Worker**:
   - 调用 Swarm 集群引擎，挂载专属协作智能体 `docs-table-worker`；
   - 注入明确的权责使命简报（负责文档表格模块的后续功能开发、块级排版与多维表格体验打磨）。
