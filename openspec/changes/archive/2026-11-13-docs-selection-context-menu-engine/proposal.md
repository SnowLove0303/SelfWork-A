# Proposal: 划选内容右键定制调整弹窗与富文本转换引擎

## Why
在《文档表格》知识库体系中，当前文档编辑器的块级操作主要依赖斜杠菜单（`/`），缺乏类似 Notion 和现代专业文档软件的直观上下文交互。用户在阅读和编辑文档时，高频需求是在选中一段文本后，直接通过鼠标右键在光标所在位置呼出专业、聚合的深色磨砂调整弹窗，一站式完成行内排版（加粗、斜体、删除线、行内代码）、色彩标注（字体色、荧光笔背景色）以及块类型无缝转换（Turn into Paragraph / H1 / H2 / H3 / Todo / Bullet / Quote / Code）。

## What Changes
1. **右键定制调整弹窗基础设施 (REQ-DOCS-CONTEXT-MENU-POPOVER-01)**：
   - 彻底拦截正文编辑区原生丑陋的浏览器右键菜单（`e.preventDefault()`）；
   - 在光标右键位置呼出深色磨砂玻璃风格的 `BlockContextMenu` 浮窗，内置视窗边缘碰撞自适应防溢出算法；
   - 监听外部点击与 `Esc` 键平滑淡出关闭。
2. **划选内容行内格式化调整 (REQ-DOCS-INLINE-FORMATTING-02)**：
   - 支持对当前划选的子文本片段执行【粗体 `**`】、【斜体 `*`】、【删除线 `~~`】、【行内代码 `` ` ``】；
   - 支持格式的反向取消（Toggle）与【清除所有格式】。
3. **字体颜色与荧光笔高亮背景色涂装 (REQ-DOCS-COLOR-HIGHLIGHT-03)**：
   - 提供语义字体色盘（默认白、绯红、暖橙、金黄、苍翠、晴蓝、浅紫）与柔和荧光底色色盘（无底、鹅黄底、薄荷绿底、冰蓝底、浅粉底、浅紫底）；
   - 对划选文字无损应用颜色与高亮样式。
4. **块级类型无损快捷转换 (REQ-DOCS-TURN-INTO-BLOCK-04)**：
   - 在右键弹窗中提供【转换为 (Turn into...)】矩阵，支持将当前块一键转换为普通段落、一级标题 (H1)、二级标题 (H2)、三级标题 (H3)、待办清单 (Todo)、无序列表 (Bullet)、引用区块 (Quote)、技术代码块 (Code)；
   - 文本内容 100% 守恒无损。
