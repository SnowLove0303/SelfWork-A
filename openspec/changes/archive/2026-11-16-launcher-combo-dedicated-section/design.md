## 2. 关键设计细节 (Key Design Details)

### 2.1 区分组合与常规单项
- 在 `LauncherDashboard.tsx` 中将 `currentItems` 派生为两个独立子集：
  ```ts
  const comboSuites = useMemo(() => currentItems.filter((i) => i.type === 'bundle'), [currentItems]);
  const standardItems = useMemo(() => currentItems.filter((i) => i.type !== 'bundle'), [currentItems]);
  ```
- 当 `comboSuites.length > 0` 时，在大盘顶部渲染专区标题与网格：
  `grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-3 mb-5`

### 2.2 宽幅组合卡片结构
- **卡片样式**：
  - 高度：`h-auto min-h-[140px] p-4`，深色晶体半透背板，搭配精致玫红/青蓝发光边框 (`border-rose-500/30 bg-rose-500/[0.03]`)；
- **顶栏**：
  - 左侧：组合叠层图标（玫瑰色渐变胶囊）+ 组合名称（加粗高亮）+ 分屏徽标（`田字四分屏`）+ 屏幕指示（`屏幕 1` / `屏幕 2`）；
  - 右侧：三点操作菜单（编辑组合 / 删除）；
- **中栏：子项成员胶囊流 (Member Tags)**：
  - 自动渲染该组合包含的 2~4 个子项名称标签（带小图标），让用户一眼看清里面包含哪些具体程序或目录；
- **底栏：动作栏**：
  - 显著的 `[ ▶️ 启动套件并平铺 ]` 触觉按钮，具备霓虹触觉高亮反馈；
  - 呈现总项数 `共 4 项`。

### 2.3 彻底消除拥挤与文字遮挡
- 由于卡片从 136px 拓宽为 280px~360px，所有标题、徽标、子项胶囊与启动按钮均拥有充足的横向与纵向呼吸空间；
- 常规单项区仅保留 `standardItems` 与 `+ 添加启动项`，回归纯粹图标网格。
