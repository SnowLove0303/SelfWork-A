# Design: 数据库笔记抽屉适度加宽与目录大纲自由折叠架构设计

## 1. 架构与状态机设计

### 1.1 侧边抽屉尺寸拓扑 (SidePeekDrawer Layout)
- 既有架构：`isMaximized ? 'w-full' : 'w-[580px] shrink-0'`。
- 升级拓扑：`isMaximized ? 'w-full' : 'w-[780px] max-w-[85vw] shrink-0'`。
- 约束说明：
  - 采用 Tailwind 原生类 `w-[780px] max-w-[85vw] shrink-0`，确保在大屏下获得充裕书写空间，在笔记本或小屏缩放下保证不会溢出视窗。
  - 继承 `transition-all duration-200` 平滑过渡动画。

### 1.2 目录大纲折叠状态机 (Outline Toggle Statechart)
```text
               ┌────────────────────────────────────────────────────────┐
               │              BlockEditor 初始化 (默认 showOutline=true) │
               └───────────────────────────┬────────────────────────────┘
                                           │
                                           ▼
             ┌───────────────────────────────────────────────────────────┐
             │                   大纲展开状态 (Expanded)                  │
             │ - 右侧渲染目录大纲栏 (w-56 lg:w-64)                       │
             │ - 大纲栏顶栏右侧展示 PanelRightClose 收起按钮              │
             │ - 顶栏操作区隐藏展开按钮                                   │
             └─────────────────────────────┬─────────────────────────────┘
                                           │
                          用户点击“收起大纲” (setShowOutline(false))
                                           │
                                           ▼
             ┌───────────────────────────────────────────────────────────┐
             │                   大纲折叠状态 (Collapsed)                 │
             │ - 右侧目录大纲栏完全卸载/隐藏                             │
             │ - 正文编辑区宽度 100% 自动扩展                             │
             │ - 顶栏右上角展示“展开目录大纲”按钮 (带 ListTree 图标与计数)│
             └─────────────────────────────┬─────────────────────────────┘
                                           │
                          用户点击“展开大纲” (setShowOutline(true))
                                           │
                                           ▼
                                 [回到大纲展开状态]
```

## 2. 影响范围与爆炸半径控制
- 核心修改仅涉及：
  1. `src/components/docs/SidePeekDrawer.tsx`：容器类名宽度微调；
  2. `src/components/docs/editor/BlockEditor.tsx`：大纲折叠状态切换与顶栏/大纲栏操作按钮注入。
- 不触碰任何底层数据库存储、SQL 引擎、Block 序列化逻辑与主导航路由。
