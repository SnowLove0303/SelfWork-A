# Proposal: 清理文档编辑区右上角冗余快捷操作按钮组

## 1. 为什么做 (Why)
用户反馈在笔记编辑界面的右上角顶栏中，`[目录]`、`[H1 标题]`、`[待办]`、`[<> 代码]` 等快捷按钮占用了顶栏空间，且与用户基于标准块编辑快捷键及斜杠命令（输入 `/` 呼出类型菜单）的操作流冲突，显得杂乱冗余。用户明确要求移除这些按钮。

## 2. 核心改动 (What Changes)
- **清理顶栏冗余按钮**：彻底移除 `src/components/docs/editor/BlockEditor.tsx` 右上角的快捷操作条（包含 `目录`、`标题`、`待办`、`代码` 按钮及其分割线）。
- **净化无用依赖**：清理不再被引用的图标导入（`Heading1`、`CheckSquare`、`Code`），确保 TypeScript 编译 `--max-warnings=0` 零告警。
- **保留沉浸式流式编辑**：用户继续通过正文原生回车、退格及 `/` 斜杠菜单快速插入各类块，右侧目录大纲栏持续保持自然呈现与跳转。

## 3. Spec-Kit 需求物理对账矩阵 (RTM 1:1 守恒)
- **REQ-DOC-PURGE-TOOLBAR-01**: 彻底移除文档编辑区顶栏右上角 `[目录]`、`[标题]`、`[待办]`、`[代码]` 按钮组，实现纯粹极简的沉浸式编辑顶栏。
