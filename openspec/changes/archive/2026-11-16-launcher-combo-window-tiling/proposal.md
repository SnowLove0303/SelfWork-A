# Proposal: 快速启动组合智能分屏编排与窗口位置自动吸附 (Window Snap Tiling)

## Why
用户提出：“研究一下有没有办法 在快速启动项功能做这种组合启动的屏幕位置编排”，并提供了多目录窗口整齐呈现为 2×2 田字格四分屏（无重叠、无空隙平铺）的实拍截图。当前快速启动的“启动组合”虽然能够批量唤起多个启动项，但新打开的窗口默认由 Windows 随意重叠堆砌，用户每次都需要手动拉伸、缩放、拖拽摆放窗口，严重降低多目录对账与多任务比对的效率。因此，必须在快速启动组合模块中引入原生智能分屏编排引擎，支持在保存组合时为子项分配屏幕象限，并在启动组合时毫秒级自动将各窗口精准吸附到对应屏幕区域。

## What Changes
1. **数据模型扩展 (`src/types/launcher.ts`)**:
   - 在 `LauncherItem` 中扩展 `windowLayout?: WindowLayoutConfig` 属性；
   - 支持多种分屏布局模式：`none`（常规）、`grid-4`（田字格四等分 2×2，核心目标）、`split-h`（左右 1:1 双分屏）、`split-v`（上下 1:1 双分屏）、`main-aside-3`（左主右辅三分屏）；
   - 定义槽位配置 `slots: WindowSlotConfig[]`，记录每个槽位对应的启动项 ID 与归一化屏幕矩形比例（`xRatio, yRatio, wRatio, hRatio`）。
2. **组合弹窗可视化分屏编排 UI (`src/components/LauncherDashboard.tsx`)**:
   - 在“创建/编辑启动组合”模态框中新增【🖥️ 屏幕窗口布局编排】配置区；
   - 提供可视化布局模板微缩卡片（田字四分屏、左右二分屏、上下二分屏、三分屏）；
   - 提供直观的槽位指派器：选择模板后呈现微缩象限网格，用户可将已选子项直观分配至各象限（左上、右上、左下、右下）；
   - 未开启编排时保持默认常规启动行为，100% 保持向后兼容。
3. **Rust 原生窗口位置自动化编排指令 (`src-tauri/src/lib.rs`)**:
   - 新增 Tauri 命令 `arrange_combo_windows(specs: Vec<WindowPlacementSpec>)`；
   - 自动调用 Win32 `SystemParametersInfoW(SPI_GETWORKAREA)` 获取主屏幕真实可用工作区尺寸（自动扣除任务栏高度）；
   - 自动捕获各目标对应的窗口句柄（针对资源管理器窗口通过 `Shell.Application` 精准匹配路径；针对普通应用程序通过 `EnumWindows` 匹配进程与标题）；
   - 毫秒级调用 Win32 原生 `SetWindowPos` 将窗口移动并平铺至对应象限；
   - 组合启动管线在唤起各目标后，自动触发该排版指令，瞬间呈现整齐划一的四分屏工作台。
