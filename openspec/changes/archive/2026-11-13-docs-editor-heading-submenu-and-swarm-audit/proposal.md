# Proposal: 右键标题二级子弹窗收拢、专属文档编辑MCP与Swarm蜂群众测审计

## Why
在《文档表格》富文本编辑体验升级过程中，用户提出三大核心诉求：
1. **右键菜单视觉收拢与二级子弹窗**：原右键菜单在“转换为 (Turn into)”中直接平铺展示 H1、H2、H3，占用了较多垂直纵深。需将其合并收敛为一个“标题 (Headings) ▷”条目，悬浮或点击时滑出二级子弹窗（Submenu），展开一级大标题、二级小节、三级重点供用户点选，极大提升主菜单紧凑度与桌面软件专业质感。
2. **构建专属文档编辑与测试 MCP 工具集**：为使 AI 智能体能跨进程直接操控文档块、注入富文本排版标签、测试边界异常并断言最终渲染状态，需构建一套专注文档编辑原子操作的测试与控制 MCP 服务。
3. **原生 Swarm 蜂群协同与敌手式双向审计**：通过 Antigravity 原生 `swarm` 工具调度专门的测试 Worker（`doc-tester`），对文档输入、连续打字、回车裂变、退格熔断、选区右键上色、二级标题转换等全套能力进行极限压力测试；由 Coordinator 进行裁执物理隔离与敌手式深度认知审计，全面揪出并根治编辑功能“不到位”的短板。

## What Changes
1. **右键标题二级子弹窗收拢 (REQ-DOCS-HEADING-SUBMENU-01)**：
   - 在 `BlockContextMenu.tsx` 的“转换为...”列表中将 H1、H2、H3 合并为【标题 (Headings) ▷】；
   - 悬浮或点击时展示自适应二级浮窗，展示 H1/H2/H3，点击子选项无损转换块类型并关闭全部菜单。
2. **构建文档编辑 MCP 测试中枢 (REQ-DOCS-EDITOR-MCP-02)**：
   - 建立专用自动化控制与断言 MCP 工具/脚本，支持块读写、排版标记注入、格式剥离与渲染对账。
3. **Swarm 蜂群编排与极端边界实测 (REQ-DOCS-SWARM-COLLAB-03)**：
   - 建立 Swarm 协同看板，派发专职测试 Worker（`doc-tester`）针对现有与新增编辑功能进行自动化与交互压力测试。
4. **两阶双轨敌手式深度认知审计与缺陷根治闭环 (REQ-DOCS-AUDIT-CLOSURE-04)**：
   - 对 Worker 发现的所有“不到位”功能进行 5-Whys 根因分析，并在 `BlockItem.tsx` 等代码中予以彻底根治与验证核销。
