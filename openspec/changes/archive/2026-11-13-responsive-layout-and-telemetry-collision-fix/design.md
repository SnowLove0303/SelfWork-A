# Design: 全局防挤压与控制台物理隔离技术架构

## 1. 架构方案与技术原理

### 1.1 容器驱动的卡片自适应网格 (Container-Driven Auto-Fill)
- **根因分析**：原实现使用 `grid-cols-2 sm:grid-cols-3 md:grid-cols-4 lg:grid-cols-5 xl:grid-cols-6`，依赖全局窗口媒体查询 (`@media min-width`)。在窗口中等但左右面板并存时，中间容器宽度可能仅 250px，却被强制塞入 4~5 列，单列只有 50px，造成卡片灾难性变形。
- **解法**：改为 CSS 容器级动态栅格：
  `grid gap-3.5` 并注入内联样式或自定义类 `gridTemplateColumns: 'repeat(auto-fill, minmax(136px, 1fr))'`。
  无论父级分配 200px 还是 1200px，网格始终确保每个卡片宽度 $\ge 136\text{px}$，自动计算最佳列数。

### 1.2 主工具栏与报文控制台隔离治理
- **根因分析**：主大盘容器与报文面板为兄弟 flex 节点。主工具栏右侧按钮众多，总宽超过中间容器宽度时，向右溢出碰撞到报文控制台左边缘。
- **解法**：
  1. 主工具栏右侧操作区声明 `min-w-0 overflow-x-auto no-scrollbar`，为搜索框注入响应式弹性伸缩 `w-32 md:w-40 min-w-[100px]`；
  2. 启动各项按钮增加 `shrink-0`，确保文字图标不崩塌；
  3. 分类侧栏宽度优化为 `w-48 lg:w-56 shrink-0`（释放 40~60px 宽度给中间）；
  4. 报文面板宽度优化为 `w-[320px] xl:w-[380px] shrink-0`，使紧凑窗口下中间区仍拥有充裕空间。

### 1.3 报文控制台页眉排版精炼
- 过滤胶囊采用紧凑字体与内边距：`text-[9px] px-1 py-0.5`。
- 滚屏、复制、清屏按钮采用微型紧凑触觉图标，文本标签仅在超宽视口露出（`hidden xl:inline`）。
- 关闭按钮（X）锁定在顶栏最右侧（`shrink-0 ml-auto`），确保 100% 可见、随时可关闭。

## 2. 影响与回归评估
- 仅重构表现层排版与栅格 CSS，不改变任何业务状态管理、SQLite 存储及 Tauri IPC 命令。
- 零新增外部 npm 依赖。
