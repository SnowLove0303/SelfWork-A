# Proposal: 快速启动添加流程极简重构 (原生资源管理器选文件/网页仅需URL)

## 1. 为什么做 (Why)
用户反馈当前添加新启动项的表单过于繁琐复杂，极其不利于新手：
1. **路径输入门槛过高**：需要手动输入或外部复制应用程序/快捷方式的绝对文件路径，对普通用户门槛高且易出错。
2. **缺乏系统原生资源管理器选择**：没有直观的“浏览/选择文件”入口，无法在 Windows 资源管理器中直观点击选择 `.exe` 或 `.lnk`。
3. **网页类型表单过于复杂**：添加网页时展示了与网页无关的启动参数、工作目录等冗余字段，认知负担大。

## 2. 核心改动 (What Changes)
- **原生文件选择器桥接**：在后端 Rust `lib.rs` 增加 `pick_launcher_file` 原生命令，支持一键拉起 Windows 原生资源管理器文件/文件夹选择器。
- **智能路径与名称填充**：选中文件后，自动将完整路径填入目标框，并智能提取文件名作为推荐名称（如选中 `Weixin.exe` 自动填入 `Weixin`，选中 `.lnk` 自动提取快捷方式名），类型自动归类为应用或脚本。
- **网页类型极简模式**：当切换为“网页直达”时，界面收敛为纯粹的“网址 (URL)”与“名称”，彻底隐藏无关的高级技术字段。
- **高级选项默认折叠**：将启动参数、工作目录、辅助描述等技术性选项收纳进“高级选项 (可选)”可折叠抽屉中，使新手界面保持清爽极简。

## 3. Spec-Kit 需求物理对账矩阵 (RTM 1:1 守恒)
- **REQ-LAUNCHER-NATIVE-PICKER-01**: 一键唤起 Windows 原生资源管理器选择文件/快捷方式，并自动填充路径与名称。
- **REQ-LAUNCHER-URL-SIMPLIFY-02**: 网页直达类型极简模式，仅需输入 URL 与名称，隐藏冗余技术参数。
