# Proposal: 思维导图管理增加回收站全生命周期治理机制

## 1. 提案背景与事实指纹溯源
- **原始需求指纹**:
  > “思维导图管理增加回收站”
- **业务痛点剖析**:
  - 当前导图卡片大盘中的删除操作为物理直接抹除（`prev.documents.filter(d => d.id !== id)`），缺乏误删防护网与反悔通道；
  - 缺乏草稿归档与定期废件清理机制，导致用户在清理过期导图时存在心理负担；
- **治理目标**:
  - 引入软删除生命周期状态，删除导图时打上 `isDeleted: true` 标记并记录 `deletedAt`；
  - 在左侧侧栏设立独立的“回收站”视图入口与动态计数徽标；
  - 在右侧大盘提供专属回收站视图，支持单篇导图原位还原、物理彻底粉碎及全量一键清空；
  - 严格保持 49px 顶标线与跨模块空间零跳移基准不变。

## 2. 1:1 需求物理对账矩阵 (RTM)

| 需求编号 | Spec-Kit 需求条目 | 拟定解决方案与边界 | 验收充要条件 |
| :--- | :--- | :--- | :--- |
| `REQ-RECYCLE-01` | 导图删除进入回收站 (软删除) | `MindMapDocument` 新增 `isDeleted?: boolean` 与 `deletedAt?: number`；卡片删除变更为软删除流转。 | 常规大盘删除后，卡片移入回收站，节点数据毫发无损。 |
| `REQ-RECYCLE-02` | 左侧分区栏专设回收站入口与徽标 | 左侧侧栏底部独立设立“回收站”栏目，展示 `Trash2` 图标与已废弃导图数徽标；点击切入回收站大盘。 | 侧栏独立显示回收站，徽标实时响应增减，点击高亮切换。 |
| `REQ-RECYCLE-03` | 回收站大盘展示与单篇导图恢复/粉碎 | 回收站专属网格卡片标注文档标题、原所属分区名与删除时间戳；提供一键“恢复”（原位还原）与“彻底删除”（物理销毁）。 | 点击“恢复”立即返回原分区；点击“彻底删除”永久物理移除；支持空状态展示。 |
| `REQ-RECYCLE-04` | 一键清空回收站治理 | 顶部工具栏在回收站视图下提供“清空回收站”动作按钮，支持二次防误触确认。 | 一键物理抹除全部已废弃导图，回收站计数清零。 |
| `REQ-RECYCLE-05` | 历史数据兼容与全局架构承重墙保护 | 历史无 `isDeleted` 标记数据默认为活跃文档；维持 `Sidebar.tsx` / `Titlebar.tsx` 0 行修改；维持 `h-[49px]` 顶栏绝对平齐。 | 历史数据平滑迁移，全局架构承重墙 100% 守恒。 |
