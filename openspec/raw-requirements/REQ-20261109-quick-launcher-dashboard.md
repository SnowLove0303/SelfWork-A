## 3. Spec-Kit 三要素展开定义

### 【条目 1】wll 启动器全指令解构与映射 (REQ-QL-01)
- **场景故事**：用户原本在 PowerShell 终端输入 `wll` 或数字菜单，希望在 SW 工作台中无需记忆繁琐命令，直观掌控所有本地服务与套件。
- **功能契约**：
  - 系统 SHALL 全面整合 wll 的 6 大核心业务集群：
    1. **常用办公套件** (`wll apps`): Antigravity + 微信 + 企业微信 + FlClash + ChatGPT + GLaDOS 签到
    2. **AI 桌面协同套件** (`wll ai-suite`): Antigravity, Antigravity IDE, ChatGPT, Cockpit 5000
    3. **核心研发平台** (`wll dsh / aistudy / studypower / web / compliance / msds`): DeepSeek Harness, AI Study, StudyPower, 冠志通 Docker Web, MSDS-Engine
    4. **网络与安全控制** (`wll lan on/off`): 冠志通 Docker 局域网访问控制
    5. **飞书与守护服务** (`wll feishu / feishu-opencode / feishu-ag`): OpenCode 2 与 Antigravity 飞书双桥接
    6. **WSL 专区 (Ubuntu)** (`wll wsl / dsh-wsl / antigravity-wsl`): WSL 容器化模型与 GUI 调度
- **验收指标**：所有 6 大类能力均有清晰对应的配置项与调度动作。

### 【条目 2】左侧仪表盘开关架构 (REQ-QL-02)
- **场景故事**：用户打开“快速启动”，左侧呈现充满现代工业与座舱科技感的开关矩阵，各个组件的状态一目了然。
- **功能契约**：
  - 左侧视口 SHALL 采用分分类别的仪表卡片布局（常用推荐、AI 套件、核心平台、飞书/守护、WSL、自动化）；
  - 每项配有：触觉拨动开关 (Switch Toggle)、状态呼吸灯 (Status Glow)、端口/链接快捷跳转胶囊、快速操作菜单；
  - 顶部配备全套一键操作总控栏（一键启动全部、一键关闭全部、综合状态巡检）。
- **验收指标**：各开关状态切换直观清脆，符合触觉按钮标准。

### 【条目 3】右侧执行报文终端 (REQ-QL-03)
- **场景故事**：用户点击开关后，右侧控制台实时弹出执行日志，让用户对后台脚本执行步骤、PID、端口和输出有确定性的把握。
- **功能契约**：
  - 右侧视口 SHALL 为深邃高透亚克力控制台窗口；
  - 实时接收进程输出，每行日志格式化显示：时间戳、日志级别标签（`[INFO]` 青、`[SUCCESS]` 绿、`[WARN]` 黄、`[ERROR]` 红）、报文正文；
  - 顶部操作栏提供：清屏按钮 (Clear)、复制全部报文 (Copy)、自动滚屏锁定 (Auto-Scroll)。
- **验收指标**：日志流式输出不掉帧，字体采用等宽代码字体，排版利落。

### 【条目 4】Tauri IPC 管道与异步状态流 (REQ-QL-04)
- **场景故事**：用户点击启动或停止时，操作在后台异步进行，前端界面保持丝滑响应，执行过程中的控制台输出实时回传。
- **功能契约**：
  - Tauri 后端提供统一 IPC 接口调度 PowerShell 脚本；
  - 支持轮询探测各服务的运行状态（基于端口监听与进程探测）；
  - 异常情况（如未装 Docker 或路径缺失）输出友好的 ERROR 报文，不导致主进程崩溃。
- **验收指标**：进程调度稳定，退出码与错误报文捕获完整。

### 【条目 5】既有不变量守恒 (REQ-QL-05)
- **场景故事**：新模块作为可插拔视口嵌入主舞台，绝对不破坏之前建立的承重墙。
- **功能契约**：
  - 44px 绝对平齐基准线、1px 单边框主干、微软雅黑字体、流体发光 Logo、免黑框 EXE 保持现状。
- **验收指标**：`pnpm check` 与 `pnpm build` 退出码 0。
