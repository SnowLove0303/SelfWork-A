## 3. Spec-Kit 三要素展开定义

### 【条目 1】嵌入式本地数据库接入与安全落盘 (REQ-DB-01)
- **场景故事**：用户在工作台里添加了多个待办与重要备忘，即便清理了系统临时文件、重装了 WebView2 或重启了电脑，核心数据绝不会意外丢失。
- **功能契约**：
  - 系统 SHALL 采用嵌入式 SQLite 作为权威持久化存储层；
  - 数据库文件物理落盘于用户标准安全路径（`selfwork.db`）；
  - 启动阶段执行原子初始化（`CREATE TABLE IF NOT EXISTS`），确保各数据表结构自愈；
  - 具备 WAL 预写日志与事务提交机制，杜绝断电或异常终止引起的文件损坏。
- **验收指标**：本地文件系统中存在真实 `selfwork.db`，支持标准 SQLite 工具打开读取。

### 【条目 2】待办清单全生命周期数据库管理 (REQ-DB-02)
- **场景故事**：用户录入待办任务，打勾完成或者调整优先级，所有变更即刻落盘；重启电脑后，任务列表与当前完全一致。
- **功能契约**：
  - `tasks` 表字段契约：`id` (TEXT PK), `title` (TEXT), `status` (TEXT), `priority` (TEXT), `is_today` (INTEGER), `due_date` (TEXT), `created_at` (INTEGER), `completed_at` (INTEGER), `updated_at` (INTEGER)；
  - 提供强类型查询、单项插入、状态更新、批量清理与物理删除能力。
- **验收指标**：回车新建任务与打勾操作即时触发数据库写入，重启后读取状态 100% 对齐。

### 【条目 3】灵感便签实时持久化入库 (REQ-DB-03)
- **场景故事**：用户记录了多张包含账号、服务器 IP、临时命令的便签卡片并设置了置顶和特定颜色，无论开关多少次程序，便签内容、置顶顺序与底色完全一致。
- **功能契约**：
  - `memos` 表字段契约：`id` (TEXT PK), `title` (TEXT), `content` (TEXT), `is_pinned` (INTEGER), `theme` (TEXT), `created_at` (INTEGER), `updated_at` (INTEGER)；
  - 支持就地编辑自动保存、置顶切换与色调切换的持久化。
- **验收指标**：修改便签正文失去焦点后数据库即刻更新，置顶卡片排头不变。

### 【条目 4】外观配置入库与数据平滑迁移 (REQ-DB-04)
- **场景故事**：老用户已经配置好了个性化背景图片和高精滑块透明度，接入数据库后无需重新设置，原有数据无缝迁入数据库。
- **功能契约**：
  - `settings` 表存储键值对：`key` (TEXT PK), `value` (TEXT), `updated_at` (INTEGER)；
  - 启动时若数据库为空但检测到浏览器 `localStorage` 存在既有数据，自动执行原子级迁移注入。
- **验收指标**：老用户无感升级，既有背景与设置完好复原。

### 【条目 5】单文件 EXE 绿色便携守恒 (REQ-DB-05)
- **场景故事**：工作台依然是单个 `SelfWork.exe` 绿色可执行文件，拷贝到任何 Windows 电脑无需配置数据库账号密码即可双击运行。
- **功能契约**：
  - 依赖纯粹静态链接进二进制，不增加外部服务依赖；
  - 保持黑灰白磨砂玻璃、44px 水平基准线等视觉设计体系 100% 不变量守恒。
- **验收指标**：编译与静态检查 0 错误 0 警告，离线双击运行稳定。
